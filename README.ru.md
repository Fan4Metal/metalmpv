<p align="center"><a href="README.md">English</a> | <b>Русский</b></p>

MetalMPV — видеоплеер для Windows с классической компоновкой: изображение занимает всё окно, под ним полоса перемотки и кнопки с «Воспроизвести» посередине, справа открывается плейлист. Воспроизведением занимается [libmpv](https://mpv.io) — библиотека плеера mpv, поэтому воспроизводятся практически все форматы видео и звука, с аппаратным декодированием там, где его поддерживает видеокарта. Программа рассчитана на быстрое открытие файлов и мгновенную перемотку по ключевым кадрам.

![Стартовый экран MetalMPV, внизу панель управления](images/screenshot.png)

*Снимок окна версии 0.1.0.*

## Возможности

- **Быстрый запуск**: движок воспроизведения запускается, пока создаётся окно; при повторном запуске первый кадр файла 1080p появляется примерно через 0,4 с после старта программы.
- **Мгновенная перемотка по ключевым кадрам** клавишами-стрелками, точная перемотка и покадровый переход другими клавишами (см. [Горячие клавиши](#горячие-клавиши)); каждая перемотка отображается на экране.
- **Все распространённые форматы**: MP4, MKV, AVI, MOV, WebM, TS, WMV и другие, включая звуковые файлы; субтитры рядом с видео подключаются автоматически.
- **Аппаратное декодирование** (NVDEC, D3D11VA и другие, выбор за libmpv), которое можно отключить в настройках.
- **Звуковые дорожки и субтитры** в одном окне у регулятора громкости (`T`); субтитры из отдельного файла (см. [Звук и субтитры](#звук-и-субтитры)).
- **Панель видео, звука и субтитров** (`U`): цвет изображения, масштаб и сдвиг, резкость, шумоподавление, пропорции, чересстрочность, тональная компрессия HDR и поворот; устройство вывода, каналы, усиление громкости до 200 %, нормализация, усиление речи, стерео в 5.1, сабвуфер, десятиполосный эквалайзер и передача Dolby и DTS на ресивер без декодирования; вид субтитров (см. [Панель видео, звука и субтитров](#панель-видео-звука-и-субтитров)).
- **Сведения о файле** (`I`): обложка, теги и характеристики каждой дорожки в окне поверх плеера; обложка звукового файла занимает место изображения (см. [Сведения о файле](#сведения-о-файле)).
- **Окно под изображение**: 50–200 % размера видео, наибольшее окно без чёрных полос, полный экран без чёрных полос, четыре вида интерфейса, мини-плеер поверх других окон (см. [Размер окна и виды интерфейса](#размер-окна-и-виды-интерфейса)).
- **Главы, повтор A-B, закладки, переход ко времени**: см. [Главы](#главы), [Повтор A-B](#повтор-a-b) (в том числе сохранение в отдельный файл), [Закладки](#закладки) и [Переход ко времени](#переход-ко-времени).
- **Продолжение просмотра**: фильм при повторном открытии воспроизводится с того места, где был остановлен, с выбранными в нём звуковой дорожкой и субтитрами (см. [Настройки](#настройки)).
- **Плейлист**: файлы, открытые вместе или перетащенные в окно, по желанию — файлы папки или треки альбома; поиск, списки M3U и IPTV с группами и логотипами каналов, полосы просмотра каждого файла (см. [Плейлист](#плейлист)).
- **Одно окно**: файл, открытый из Проводника при запущенном плеере, воспроизводится в уже открытом окне.
- **Типы файлов**: плеер можно зарегистрировать в Windows для его форматов, у каждого из которых свой значок (см. [Типы файлов](#типы-файлов)).
- **Интерфейс на русском или английском**: язык следует языку Windows и меняется в настройках (`F5`).
- **Портативность**: [портативный архив](#установка) хранит настройки рядом с программой.
- **Конфиденциальность**: обращений к сети нет, кроме открытых адресов, необязательной проверки обновлений и логотипов IPTV-каналов, которые можно выключить (см. [Проверка обновлений и конфиденциальность](#проверка-обновлений-и-конфиденциальность)).

## Установка

Установщик и портативный архив находятся на странице [Releases](https://github.com/Fan4Metal/metalmpv/releases). В обоих вариантах есть `libmpv-2.dll` (около 115 МБ в распакованном виде) — движок воспроизведения; файл должен лежать рядом с `metalmpv.exe`. Исполняемые файлы не подписаны, поэтому Windows SmartScreen при первом запуске может предупредить о неизвестном издателе.

- **Установщик** `MetalMPV_<версия>_Setup.exe`: права администратора не нужны; программа устанавливается в `%LOCALAPPDATA%\Programs\MetalMPV` и хранит настройки в `%APPDATA%\MetalMPV`. Задача установщика **Типы файлов**, включённая по умолчанию, регистрирует плеер для его форматов (см. [Типы файлов](#типы-файлов)); на последней странице установщик предлагает открыть параметры Windows, чтобы выбрать плеер проигрывателем по умолчанию. При удалении программы регистрация удаляется; настройки (вместе с запомненными позициями и логотипами каналов) сохраняются.
- **Портативный архив** `MetalMPV_<версия>_portable.zip`: программа в папке `MetalMPV`, работает без установки; настройки хранятся рядом с ней, поэтому программу можно переносить на съёмном носителе.

<details>
<summary>Где портативная программа хранит настройки</summary>

В архиве лежит пустой файл `metalmpv.ron`. Пока этот файл находится рядом с `metalmpv.exe` и папка доступна для записи, настройки хранятся в нём. Без этого файла настройки хранятся в `%APPDATA%\MetalMPV`, как у установленной программы. Окно «О программе» показывает, где хранятся настройки.

Рядом с файлом настроек лежит его копия, сделанная при каждом запуске (`app.ron.bak` или `metalmpv.ron.bak`); повреждённый файл настроек, например при отключении питания во время записи, заменяется этой копией.

</details>

## Использование

### Открытие файлов

Файл открывается кнопкой **Открыть файл** (значок извлечения, `Ctrl+O`), перетаскиванием в окно, из Проводника (**Открыть с помощью**) или из командной строки: `metalmpv.exe файл.mkv [другие файлы]`. Несколько файлов образуют плейлист; по окончании файла начинается следующий. `Ctrl+U` или пункт **Открыть адрес…** контекстного меню воспроизводит прямую ссылку на видео или поток. Пока ничего не воспроизводится, стартовый экран показывает последние воспроизведённые файлы.

<details>
<summary>Перетаскивание, списки M3U и IPTV, адреса, недавние файлы, панель задач</summary>

- **Перетащенные файлы** добавляются в конец плейлиста и сразу воспроизводятся, только если плейлист был пуст или ничего не воспроизводится (файл, который уже есть в плейлисте, тогда воспроизводится со своего места; о добавленных при скрытом плейлисте сообщает экранное сообщение). Файл субтитров, перетащенный вместе с видео, когда ничего не воспроизводится, подключается к этому видео.
- **Плейлисты M3U и M3U8**, открытые, перетащенные или переданные в командной строке, заменяются своими записями: относительные пути отсчитываются от папки плейлиста, адреса `file:///` считаются путями, а файл `.m3u` не в UTF-8 читается в кодировке системы, как его записывали старые плееры. Плейлист потока HLS, с тегами `#EXT-X-`, воспроизводится как один поток. Так же, как только mpv его прочитает, заменяется плейлист по адресу (`http://…/list.m3u`) и плейлист, указанный внутри другого. Из адресов списка воспроизводятся только потоки (http, https, rtsp, rtmp, udp и подобные); список, открытый по адресу, не указывает на файлы компьютера.
- **Списки IPTV**: строки `#EXTINF` задают названия записей. Плейлист, заголовок окна и сохранённые кадры показывают название канала вместо имени файла потока, подсказка записи — её группу, а рядом с названием показывается логотип канала (`tvg-logo`; см. **Логотипы каналов** в настройках); **Сохранить плейлист** записывает названия, логотипы и группы обратно.
- **Адреса**: прямая ссылка на видео или поток (http, https, rtsp, rtmp, udp и другие; адрес в командной строке тоже принимается). Страницы YouTube и других сайтов не поддерживаются, поскольку плеер не использует yt-dlp.
- **Недавние файлы**: стартовый экран показывает под заголовком НЕДАВНИЕ, по центру под подсказкой, последние воспроизведённые файлы (до восьми, сколько позволяет высота окна; остальные из тридцати запомненных прокручиваются на их месте). Щелчок воспроизводит файл, а **Очистить список** очищает список, как и **Забыть всё** в разделе «Продолжение просмотра» настроек. При выключенной настройке **Запоминать недавние файлы** файлы не запоминаются.
- **Панель задач**: кнопка программы показывает позицию как индикатор выполнения (жёлтый на паузе), а под её миниатюрой есть кнопки **Предыдущий файл**, **Воспроизвести**/**Пауза** и **Следующий файл**.
- **Спящий режим**: пока воспроизводится видео, экран не гаснет и компьютер не засыпает; пока звучит только звук, компьютер не засыпает, а на паузе и после окончания воспроизведения снова действуют настройки электропитания Windows.

</details>

### Окно и полноэкранный режим

У окна собственная строка заголовка: окно перемещается перетаскиванием заголовка, изображения или свободного места панели управления, меняет размер за края и разворачивается двойным щелчком по заголовку. Двойной щелчок по изображению или `Enter` включает полноэкранный режим, в котором остаётся только изображение; панель управления внизу и название файла вверху появляются поверх него независимо друг от друга, каждая — пока указатель находится у её края, а сам указатель скрывается через полсекунды покоя вдали от них. Полосу с названием можно отключить, а прозрачность обеих панелей задаётся в настройках. `L` или средний щелчок показывает плейлист поверх правой части экрана, на всю его высоту; ширина меняется перетаскиванием левого края; `Esc` или та же клавиша скрывает его, как и выход из полноэкранного режима.

На панели управления расположены полоса перемотки (щелчок или перетаскивание переводит воспроизведение в эту точку, время под указателем показывается в подсказке), время (щелчок по нему переключает текущую позицию с длительностью, только текущую позицию и оставшееся время; выбор сохраняется), кнопки **Открыть файл**, **Стоп**, **Предыдущий файл**, **Воспроизвести/Пауза**, **Следующий файл**, **Настройки** и **Плейлист**, кнопки панели «Видео, звук и субтитры» и дорожек, кнопка звука с громкостью и кнопка полноэкранного режима. Щелчок правой кнопкой по изображению открывает меню с теми же командами.

### Размер окна и виды интерфейса

`1`–`4` подгоняют окно под 50 %, 100 %, 150 % или 200 % размера видео, `5` делает наибольшее окно без чёрных полос, `` ` `` (клавиша слева от `1`) подгоняет окно под изображение, а `6` включает полноэкранный режим с изображением, обрезанным до заполнения экрана. `8` переключает четыре вида интерфейса, `7` оставляет только изображение, а `0` превращает окно в мини-плеер. Те же команды собраны в подменю **Масштаб** и **Интерфейс** контекстного меню изображения.

<details>
<summary>Подробнее о размере окна и видах интерфейса</summary>

- **Окно под изображение**: при 100 % пиксель видео приходится на пиксель экрана. `5` делает окно наибольшим из помещающихся на экране, в пропорциях изображения, а `` ` `` подгоняет окно под показанное изображение, убирая чёрные полосы. Развёрнутое окно сначала восстанавливается, полноэкранный режим выключается; окно, которое не поместилось бы на экране, уменьшается с сохранением пропорций изображения и по возможности сохраняет своё положение по центру.
- **Полный экран без чёрных полос**: `6` увеличивает изображение до заполнения экрана с обрезкой краёв; повторное нажатие `6` снова показывает изображение целиком, с чёрными полосами, не выходя из полноэкранного режима; выход из полноэкранного режима тоже возвращает изображение целиком.
- **Виды интерфейса**: **Полный** (строка заголовка и панель управления в две строки), **Без заголовка**, **Компактный** (без строки заголовка, панель управления в одну строку: слева воспроизведение, предыдущий и следующий файлы, время и полоса перемотки, справа громкость и остальные кнопки; открытие файла и остановка остаются в контекстном меню и на клавишах, а в узком окне менее нужные кнопки скрываются, чтобы полоса перемотки сохранила место) и **Только видео**. Без строки заголовка она вместе с кнопками окна появляется поверх верхнего края изображения, пока там находится указатель. Вид сохраняется между запусками (выбирается также на странице «Общие» настроек); в полноэкранном режиме при компактном виде панель управления тоже компактная. При смене вида окно увеличивается или уменьшается на разницу, так что изображение остаётся на прежнем месте и того же размера; развёрнутое или полноэкранное окно сохраняет размер и подгоняется после восстановления.
- **Только видео** (`7`) скрывает строку заголовка, панель управления и плейлист. Строка заголовка появляется поверх верхнего края изображения, а панель управления выбранного вида — поверх нижнего, пока указатель находится у края, и окно по-прежнему перемещается перетаскиванием изображения и меняет размер за края. Повторное `7`, `Esc` или пункт **Вернуть интерфейс** в начале контекстного меню возвращает вид, показанный до этого (полный, если программа запущена в режиме «только видео»); то же делает запрос плейлиста (`L`, средний щелчок, контекстное меню), который при этом показывается.
- **Мини-плеер** (`0`, кнопка слева от «Свернуть» в строке заголовка или пункт **Мини-плеер** контекстного меню): окно становится маленьким и находится поверх других окон, показывая только изображение; в первый раз оно шириной 384 точки в правом нижнем углу экрана, затем там, где его оставили, и того же размера. Его пропорции следуют за изображением, в том числе при перетаскивании краёв и при открытии другого файла, а при перемещении оно притягивается к краям и углам экрана. Пока указатель движется над изображением или ничего не воспроизводится, внизу появляются воспроизведение, звук и громкость и полоса перемотки, а в правом верхнем углу — кнопка возврата к окну плеера. Окно перемещается перетаскиванием изображения, колесо меняет громкость, клавиши работают как обычно. Повторное `0`, двойной щелчок по изображению, та же кнопка или пункт **Окно плеера** в начале контекстного меню возвращают то, что было до него: окно в прежнем виде, развёрнутым, если оно было развёрнуто, или полноэкранный режим; `Esc` возвращает окно; то же делают плейлист, полноэкранный режим, размеры окна, виды интерфейса, окно дорожек, панель и сведения о файле.

</details>

### Плейлист

Плейлист (`L`) показывает файлы и выделяет текущий. Двойной щелчок воспроизводит файл, выбранные записи перемещаются перетаскиванием, а правая кнопка открывает меню записи. Кнопки-значки над плейлистом добавляют, убирают, упорядочивают, очищают, сохраняют и перемешивают записи и переключают режим повтора; их названия видны в подсказках. Лупа или `Ctrl+F` открывает поиск по плейлисту.

<details>
<summary>Выбор, меню, полосы просмотра, группы, поиск, кнопки, повтор</summary>

- **Выбор**: щелчок выбирает запись, `Ctrl`+щелчок добавляет запись к выбору или убирает из него, `Shift`+щелчок выбирает диапазон показанных записей (скрытые поиском или в свёрнутой группе в выбор не входят, как и при **Выделить все**). Плейлист прокручивается к текущей записи, когда она меняется.
- **Перемещение**: выбранные записи перемещаются перетаскиванием; линия показывает, куда они встанут (не во время поиска и не в группах).
- **Меню записи**: **Воспроизвести**, **Показать в папке**, **Копировать путь** (пути всех выбранных записей), **Выделить все** и **Убрать из плейлиста**.
- **Полосы просмотра**: тонкая линия под записью показывает, сколько просмотрено, а галочка справа отмечает файл, досмотренный до конца (для файлов от пяти минут, пока включено **Продолжать с места остановки**). Пункт **Показывать полосы просмотра** в меню записи отключает и включает линии (галочки остаются), выбор запоминается.
- **Группы IPTV**: записи IPTV-плейлиста с группами (`group-title`) показываются под своими группами, которые сворачиваются щелчком по заголовку; меню группы сворачивает или разворачивает их все, а пункт **Показывать группы** в меню записи или группы отключает и включает это, выбор запоминается.
- **Поиск**: лупа справа от кнопок или `Ctrl+F` показывает поле поиска. Плейлист тогда показывает записи, в названии которых есть набранный текст, `Enter` воспроизводит первую из них, а `Esc` в поле закрывает его; вне поля `Esc` действует как обычно.
- **Кнопки**: добавить файлы (**+**), убрать выбранные (**−**, `Delete`), упорядочить плейлист по имени, числа — по значению (полоски со стрелкой), очистить его (корзина), сохранить в плейлист M3U8 (стрелка в лоток), а после черты — перемешать (скрещённые стрелки; текущий файл продолжает играть и встаёт первым).
- **Повтор**: кнопка с петлёй, `R` или подменю **Повтор** контекстного меню переключает режим повтора, который запоминается: выключен, файл (воспроизводится снова без паузы) или плейлист (после последнего файла — первый; **Следующий** и **Предыдущий** ходят по кругу).

</details>

<details>
<summary>Плейлист в отдельном окне</summary>

Кнопка в правом конце ряда кнопок плейлиста (окно со стрелкой) или пункт **Плейлист в отдельном окне** контекстного меню изображения переносит плейлист в отдельное окно и обратно. Это окно, как и окно плеера, без рамки Windows: у него своя строка заголовка (за неё окно перетаскивается, справа — кнопка закрытия), а размер меняется за края; у него нет кнопки на панели задач, оно находится поверх плеера и сворачивается вместе с ним; в первый раз оно встаёт у правого края плеера во всю его высоту.

Поднесённое к краю плеера, окно притягивается к нему и выравнивается по верху, низу или боковому краю плеера; прилипнув к краю, оно перемещается вместе с плеером и следует за изменением его размера (кроме развёрнутого и полноэкранного режимов). В полноэкранном режиме окно скрыто, если оно закрывало бы экран плеера. Клавиши плеера в нём работают, кроме `Esc`, которая закрывает это окно. Положение и размер окна запоминаются.

</details>

### Панель видео, звука и субтитров

`U` (также `F7`), кнопка с ползунками слева от кнопки дорожек на панели управления или пункт **Видео, звук и субтитры…** контекстного меню изображения открывает над этой кнопкой панель с вкладками **Видео**, **Звук** и **Субтитры**. Воспроизведение и клавиши при этом продолжают работать; щелчок вне панели, повторное нажатие кнопки, `U`, `F7` или `Esc` закрывает её. Фотоаппарат в её заголовке, **Сохранить кадр** (`Ctrl+E`), сохраняет кадр на экране.

<details>
<summary>Как устроена панель</summary>

- **Место**: над своей кнопкой, как окно дорожек (в правом нижнем углу, если показано только изображение); её высота одна для всех вкладок, а если окно для неё слишком низкое, она занимает высоту над кнопкой и вкладки прокручиваются под заголовком.
- **Разделы**: на вкладках щелчок по заголовку раздела сворачивает или разворачивает его, и панель запоминает это между запусками.
- **Значения** задаются ползунками, дорожка которых подсвечивается от исходной точки до ручки, так что изменение видно сразу; стрелки на концах ползунка сдвигают значение на шаг назад или вперёд, а при удержании — шаг за шагом; значение рядом с ползунком можно также перетащить или ввести, оно выделено акцентным цветом, пока отличается от исходного, а двойной щелчок по ползунку или круговая стрелка рядом возвращает исходное. Включение и выключение — переключатели.
- **Подсказки**: подсказка каждого параметра объясняет, как он действует: на какие субтитры, на процессоре или на видеокарте, запоминается ли между запусками.
- **Сохранить кадр** сохраняет кадр в том виде, в каком он декодирован, без субтитров, в формате PNG или JPG (см. «Видео» в настройках) с названием файла и позицией в папку «Изображения\MetalMPV» или выбранную; правый щелчок по фотоаппарату предлагает **Открыть папку**.

</details>

<details>
<summary>Вкладка «Видео»</summary>

- **Цвет**: яркость, контраст, насыщенность, оттенок и гамма, от −100 до 100.
- **Масштаб** от 50 до 400 %, а под ним — навигатор: кадр в уменьшенном виде с рамкой вокруг части, видимой на экране. Рамку можно перетащить или поставить щелчком, сдвигая изображение (до ±50 % в каждую сторону); числа рядом со **Сдвигом** принимают значение с клавиатуры, а двойной щелчок по навигатору возвращает кадр в центр. **Навигатор на изображении** показывает то же в правом нижнем углу изображения, пока оно увеличено больше окна (выше места, где поверх изображения появляется панель управления).
- **Резкость** (адаптивная резкость AMD, CAS) и **шумоподавление** (от 0 — выключено — до 100 %; 40 % — обычная сила FFmpeg, больше — размывает). **Сглаживание полос градиента** убирает ступеньки на небе и в тёмных сценах.
- **Пропорции** берутся из файла или задаются принудительно: 4:3, 16:9, 16:10, 1.85:1, 2.35:1 или 2.39:1 (также в подменю **Пропорции** контекстного меню изображения).
- **Чересстрочность**: сшивает чересстрочные кадры, как в ТВ-записях, в целые: автоматически для кадров, помеченных как чересстрочные (по умолчанию), всегда или никогда.
- **HDR на SDR** выбирает, как HDR-изображение приводится к обычному экрану: автоматически, BT.2390 (по стандарту), Hable (кинематографичный), Möbius (яркий), Reinhard (мягкий) или обрезкой.
- **Повороты и отражения**: ряд из четырёх кнопок-значков, названия которых видны в подсказках, поворачивает изображение влево или вправо на 90°, переворачивает его вертикально или отражает зеркально (включённые отражения подсвечены).

Резкость, шумоподавление и отражения — фильтры FFmpeg, их выполняет процессор (пока включён любой из них, при аппаратном декодировании каждый кадр копируется для них обратно в память); остальное выполняет видеокарта. Настройки действуют для всех файлов до закрытия программы, а при включённом **Запоминать** — и между запусками; **Сбросить всё** возвращает исходные значения.

</details>

<details>
<summary>Вкладка «Звук»</summary>

Вкладка (её открывает и действие «Эквалайзер», у которого нет клавиши по умолчанию) начинается с того, что сейчас играет: каналы дорожки нарисованы динамиками вокруг слушателя (а если звук сводится для устройства в другие каналы — стрелка к значку каналов устройства), рядом — формат так, как его называет декодер (E-AC3 Atmos, DTS-HD MA и подобные; полное имя кодека в подсказке), каналы, частота дискретизации и текущий битрейт, а также что получает устройство (частота, каналы и формат отсчётов либо битовый поток, передаваемый на ресивер). Далее она содержит:

- **Устройство вывода**: пока выбранное отключено, звук идёт через устройство Windows по умолчанию.
- **Каналы**: «Авто» следует настройке устройства в Windows; моно, стерео, 5.1 или 7.1 сводят звук в эту раскладку.
- **Ресивер**: передача звука Dolby и DTS в сжатом виде, чтобы его декодировал ресивер (по S/PDIF — AC3 и DTS, по HDMI — также E-AC3, DTS-HD и TrueHD). Громкость, нормализация, эквалайзер и каналы плеера на него не действуют, Windows отдаёт устройство только плееру, а формат, который устройство не принимает, декодируется как обычно.
- **Усиление громкости**: до 130, 150 или 200 %; на громких местах возможны искажения.
- **Задержка** звука относительно изображения: ползунок ±5 с; клавишами можно дальше, между запусками не запоминается.
- **Нормализация** (фильтр FFmpeg `dynaudnorm`): тихие диалоги громче, громкие сцены тише; её **Сила** — мягкая, средняя или сильная — поднимает тихие места до 3, 5 или 10 раз, сильная подстраивается быстрее всех.
- **Усилить речь** — подъём голоса над музыкой: в стереодорожке фильтром FFmpeg для диалогов, в дорожке 5.1 и больше — подъёмом центрального канала, моно остаётся как есть. Его **Сила**, от +1 до +20 дБ (по умолчанию +4), — насколько голос громче остального: центральный канал поднимается до 12 дБ, сильнее — вместо этого приглушаются остальные каналы, чтобы громкий голос не хрипел; в стерео сначала с той же силой работает фильтр для диалогов (до своего предела на 12 дБ).
- **Стерео в 5.1** — раскладка стереодорожки на 5.1 для акустики, которая его принимает (фильтр FFmpeg `surround`: общее для обеих сторон, в основном голос, уходит в центр, различия — в тыловые, низкие частоты — на сабвуфер; «Усилить речь» тогда поднимает этот центр); недоступна, пока «Каналы» сводят звук в моно или стерео. Под ней **Сабвуфер до** задаёт частоту, ниже которой звук уходит на сабвуфер (40–200 Гц, по умолчанию 80 — разделение, принятое в кинотеатрах; выше неё он затухает до удвоенной частоты), а **Басы только в сабвуфер** убирает низкие частоты из остальных колонок, а не только дублирует их в сабвуфер, — для небольших фронтальных колонок.
- **Сабвуфер**: его **Уровень** в дБ (от −20 до +10) — для дорожки 5.1 или 7.1 относительно уровня в самой дорожке, для «Стерео в 5.1» относительно стандарта 5.1, на 10 дБ ниже остальных каналов, поскольку ресиверы воспроизводят этот канал на 10 дБ громче; и **Срез инфранизких**, убирающий во всех каналах то, что ниже заданной частоты (15–40 Гц, по умолчанию 25; 24 дБ на октаву): сабвуфер это почти не воспроизводит, но его диффузор доходит до предела хода и бас булькает, а в фильмах с глубоким басом такого много.
- **Эквалайзер**: десять полос от 31 Гц до 16 кГц, ±12 дБ на полосу (двойной щелчок или круговая стрелка под полосой возвращает 0), со шкалой ±12 дБ, линией 0 дБ и кривой через полосы. Переключатель включает его, а список рядом содержит предустановки «Ровно», «Рок», «Поп», «Джаз», «Классика», «Басы», «Голос» и «Высокие». Плюс рядом со списком сохраняет полосы под названием, которое вводится в появившейся строке (Enter сохраняет, Esc отменяет; с тем же названием заменяется); такие наборы идут в списке после предустановок, под заголовком «Мои», не более двадцати, а корзина удаляет выбранный.

Настройки функции видны, только пока она включена. **Сбросить всё** возвращает остальное, включая задержку; устройство вывода, ресивер и свои наборы эквалайзера остаются. Всё, кроме задержки, запоминается между запусками; эквалайзер, нормализация и усиление речи не действуют на звук, передаваемый на ресивер без декодирования.

</details>

<details>
<summary>Вкладка «Субтитры»</summary>

- **Заготовки**: сначала готовые — мягкие с тенью (по умолчанию), классические как в mpv, с тонкой обводкой, жирные с толстой обводкой, только тень без обводки, кремовые, бледно-мятные, на тёмной подложке и тёмные на светлой подложке. Каждая задаёт цвета, обводку, тень, жирность и подложку, а шрифт, размер и высоту оставляет как есть (после изменения любого из этих параметров в списке значится «Другой»).
- **Свои заготовки**: плюс рядом со списком сохраняет весь вид, включая шрифт, размер и высоту, под названием, которое вводится в появившейся строке; такие заготовки идут после готовых, под заголовком «Мои», не более двадцати, а корзина удаляет выбранную. Они запоминаются между запусками, и кнопка «Сбросить» в настройках их сохраняет.
- **Образец**: под списком крупный образец примерно показывает вид субтитров — шрифтом интерфейса и постоянного размера, на фоне от тёмного к светлому.
- **Параметры**: шрифт и размер (всех субтитров, включая ASS), жирное начертание, цвет букв и обводки, толщина обводки, тень, полупрозрачная подложка под каждой строкой вместо обводки (цвета обводки; толщина становится её полями) и высота субтитров на изображении.
- **В чёрных полях** (по умолчанию включено): если у изображения есть чёрные поля, субтитры, в том числе ASS, идут в них; выключено — поверх изображения.
- **Стиль и для ASS**: шрифт, цвета и обводка заменяют и стили субтитров ASS, надписи и эффекты в которых тогда теряют свой вид.
- **Задержка**: ползунок ±5 с, между запусками не запоминается. Под ним шкала времени показывает отрезок вокруг текущей позиции с вертикальной линией посередине; реплики субтитров из отдельного файла (SRT, WebVTT, ASS) показаны на нём блоками со сдвигом на задержку. Перетаскивание блоков задаёт задержку, а начало реплики ненадолго задерживается на линии позиции; так пауза там, где звучит реплика, и её блок на линии подгоняют субтитры к речи. Кнопки-стрелки по краям ставят на текущий момент реплику до или после показанной (`Ctrl+Shift+←` и `Ctrl+Shift+→`, для любых субтитров), а − и + меняют длину отрезка, от 10 с до 5 мин 20 с.

**Сбросить всё** возвращает исходный вид. Без **Стиля и для ASS** размер и высота действуют на все субтитры, шрифт и цвета — на текстовые (SRT и подобные). Всё, кроме задержки, запоминается между запусками.

</details>

### Звук и субтитры

Кнопка с облачком речи слева от громкости (`T`) открывает окно со звуковыми дорожками и субтитрами файла. У каждой дорожки первым указан язык, за ним через тире название дорожки («Русский — Superbit»), под ними — плашки с форматом, числом каналов и пометками «внешние», «принудительные», «по умолчанию». Выбор применяется сразу, а окно остаётся открытым. **Загрузить из файла…** под субтитрами подключает субтитры из отдельного файла (SRT, ASS, SSA, VobSub, PGS, WebVTT); так же подключается файл субтитров, перетащенный на воспроизводимое видео, а субтитры с тем же именем, что у видео, рядом с ним подключаются сами.

<details>
<summary>Подробнее об окне дорожек</summary>

Два списка показаны на вкладках; кнопка справа от вкладок показывает их рядом в две колонки, а та же кнопка в этом виде возвращает вкладки (выбор запоминается между запусками). Длинный список прокручивается. Как и при панели видео, звука и субтитров, которую окно сменяет на том же месте, воспроизведение и клавиши продолжают работать, а щелчок вне окна, повторное нажатие кнопки, `T` или `Esc` закрывает его. Те же списки есть в контекстном меню изображения, а каждая смена отображается на экране.

</details>

### Главы

Если в файле есть главы, полоса перемотки разделена разрывами в начале каждой из них, а подсказка над полосой называет главу под указателем. Метки отключаются и включаются в подменю **Главы** контекстного меню изображения или в настройках (**Воспроизведение**). Под плейлистом раздел **Главы** перечисляет их с временем начала и выделяет текущую; щелчок переходит к главе, щелчок по заголовку сворачивает раздел. Тот же список есть в подменю **Главы**. Переход отображается на экране с номером и названием главы.

### Переход ко времени

`Ctrl+G` или пункт **Перейти ко времени…** контекстного меню изображения открывает окно, в поле которого стоит текущая позиция, выделенная так, что введённое время её заменяет. Поле принимает `1:23:45`, `83:20`, число секунд (`5000`), дробную часть после точки или запятой (`1:23,5`), долю файла (`50%`) или сдвиг от текущей позиции (`+30`, `-1:00`, `+10%`); под полем окно показывает время, которое получается, и его долю в файле, либо сообщает, что текст не является временем в этом файле. `Enter` или **Перейти** переходит туда с точностью до кадра; время после конца файла ведёт к концу.

### Закладки

`Ctrl+B` или пункт **Закладки → Добавить закладку здесь** контекстного меню изображения запоминает текущий файл и позицию. Подменю **Закладки** перечисляет их, последние сверху, каждую — именем файла и временем, с тонкой линией под ней, показывающей место закладки в файле; закладки текущего файла отмечены. Щелчок переходит к закладке: в текущем файле сразу, иначе её файл воспроизводится с этого места (его запись в плейлисте или открытый файл); крестик рядом удаляет закладку, а **Удалить все закладки** — все. Между запусками хранится до 30 закладок, старые уступают место; сброс настроек их не затрагивает.

### Повтор A-B

`[` отмечает начало отрезка в текущей позиции, а `]` — его конец; после этого воспроизведение каждый раз по достижении конца возвращается к началу, пока `\` не выключит повтор. Конец, отмеченный без начала, повторяет отрезок от начала файла, а конец раньше начала меняет точки местами. Точки показываются жёлтыми рисками на полосе перемотки, отрезок между ними подсвечивается, экранное сообщение называет их с точностью до десятой доли секунды, а подменю **Повтор A-B** контекстного меню изображения делает то же самое. Точки относятся к файлу: другой файл начинается без них.

`Ctrl+Shift+S` или пункт **Сохранить фрагмент…** того же подменю сохраняет отрезок между точками в отдельный файл, пока воспроизведение продолжается.

<details>
<summary>Сохранение фрагмента в файл</summary>

- **Файл**: MP4 рядом с исходным, а для адреса — в папке сохранённых кадров, со временем в имени; **…** выбирает другой. Имя без папки сохраняется в ту же папку, а к имени без `.mp4`, `.mkv` или `.mov` добавляется `.mp4`. Воспроизводимый файл и уже существующий не перезаписываются, кроме файла, замену которого подтвердил диалог **…**; он заменяется только после того, как новый файл готов.
- **Кодирование**: H.264 или HEVC, на процессоре (x264, x265) или видеокарте NVIDIA (NVENC), качество (по умолчанию 22; меньше — лучше и крупнее файл) и, при желании, показанные субтитры, впечатанные в изображение в их стиле. Звук — текущая дорожка, в AAC; задержки звука и субтитров и устранение чересстрочности берутся из плеера. Отрезок вырезается точно по точкам.
- **Ход сохранения**: затем показываются полоса прогресса и кнопки **Отмена** и **Скрыть**. Скрытое окно не мешает пользоваться плеером, пока сохранение идёт, а `Ctrl+Shift+S` показывает его снова; экранное сообщение называет сохранённый файл или причину неудачи (для NVENC нужна видеокарта NVIDIA). Выбор запоминается.

</details>

### Сведения о файле

Клавиша `I`, кнопка **i** в строке заголовка или пункт **Сведения о файле** контекстного меню изображения открывает окно поверх плеера; пока оно открыто, воспроизведение продолжается и клавиши работают, а `I` или `Esc` закрывает его. Вверху показаны обложка, название, исполнитель и альбом, под ними в рядах чипов — главное: файл, изображение и звук, по чипу на каждую звуковую дорожку (щелчок по нему включает эту дорожку), и субтитры. Ниже идут разделы со всеми подробностями о файле, воспроизведении и дорожках.

`Ctrl+I` или пункт **Сведения поверх картинки** контекстного меню показывает те же чипы отдельно, полупрозрачными, в правом верхнем углу изображения, пока `Ctrl+I` не скроет их; пока открыто окно сведений, их не видно. Включение сохраняется между запусками; на странице **Видео** настроек их можно включить и выключить, задать прозрачность их фона и параметром **Кратко** оставить одну строку о том, что воспроизводится: формат, кодек, размер и HDR изображения, звуковую дорожку и субтитры.

<details>
<summary>Что показывает окно</summary>

- **Обложка**: щелчок по ней показывает её в размере, который позволяет окно. Канал списка IPTV показывается с названием и группой из списка, а вместо обложки — его логотип, когда он загружен.
- **Чипы**: файл (формат, размер, длительность, общий битрейт), изображение (кодек, размер кадра, соотношение сторон, частота кадров, разрядность, HDR, битрейт) и звук — по чипу на каждую звуковую дорожку (кодек, каналы, язык), играющая обведена; если дорожек больше четырёх, остальные свёрнуты в один чип, который перечисляет их в подсказке и по щелчку показывает все (чип **−** после них снова сворачивает их, как и другой файл). Чип субтитров, в отдельном ряду, называет их язык и число; если дорожек больше одной, щелчок показывает вместо него по чипу на каждую, щелчок по чипу включает эти субтитры, а **−** снова сворачивает их. Подсказка каждого чипа говорит больше: название контейнера, полное имя кодека и профиль, название и характеристики дорожки. Чипы цветные: формат — цветом значка его типа файлов, изображение, звук и субтитры — каждый своим оттенком.
- **Разделы** сворачиваются щелчком по заголовку и копируются текстом из его контекстного меню:
  - **Файл**: имя, папка, размер, контейнер, длительность, общий битрейт, число глав, программа, записавшая файл Matroska, и время записи, даты файла; щелчок по папке показывает файл в Проводнике.
  - **Воспроизведение**, обновляемое каждую секунду: текущий битрейт с графиком за последнюю минуту, частота показа кадров рядом с частотой экрана, пропущенные кадры, что получает звуковое устройство (в том числе формат, передаваемый без декодирования) и для потока — объём данных, прочитанных наперёд.
  - **Теги**: распространённые — первыми и с названиями на языке интерфейса, остальные — так, как они названы в файле; длинный тег сокращается, а ссылка **ещё** показывает его целиком.
  - **Дорожки**, сгруппированные на видео, аудио и субтитры, играющая отмечена точкой; у каждой в одной строке указаны формат, размер кадра, частота кадров, разрядность, HDR, число каналов, частота дискретизации и битрейт; формат звуковой дорожки уточняется, когда его сообщает декодер (DTS-HD MA, DTS:X, E-AC3 Atmos, TrueHD Atmos, HE-AAC). Щелчок по дорожке раскрывает подробности, а показываемое видео раскрыто сразу: профиль и уровень кодека, соотношение сторон, раскладка каналов, битрейт и размер потока (из статистики, которую mkvmerge записывает в файл Matroska, иначе примерный), число кадров, признаки и теги дорожки, а для показываемого видео также цветовая субдискретизация, развёртка, диапазон цветов, основные цвета, передаточная функция и матрица, формат HDR и уровни яркости с данными дисплея мастеринга, способ декодирования (аппаратный или программный).
- **Копирование**: любое значение можно выделить, а его контекстное меню копирует значение или всю строку. Справа в строке названия расположены две кнопки-значка, названия которых видны в подсказках: **Копировать всё** (два листа) помещает все сведения в буфер обмена текстом, значения выровнены в столбец, и на мгновение показывает галочку, а **Сохранить обложку…** (стрелка в лоток) сохраняет изображение в том виде, в каком оно хранится.
- **Положение**: окно находится у правого верхнего угла плеера, в том числе после изменения размера окна плеера. Его нижний край можно перетащить, чтобы сделать окно выше или ниже.

</details>

Обложка берётся из тегов файла (MP3, FLAC, OGG, Opus, M4A, MP4, WAV, APE и другие) или из его вложений (MKV, MKA, WebM); для звукового файла без обложки используется изображение с именем `cover`, `folder` или `front` рядом с ним. Пока воспроизводится звуковой файл, его обложка занимает место изображения, а под ней указаны название, исполнитель и альбом.

### Типы файлов

Страница **Типы файлов** в настройках (`F5`) регистрирует плеер для его форматов, открывает выбор программы по умолчанию в Windows и удаляет регистрацию. Регистрация выполняется для текущего пользователя и не требует прав администратора; установщик тоже регистрирует форматы. Каждый формат получает собственный тип со значком (свой оттенок для каждого семейства форматов, на видео — знак воспроизведения, на звуке — нота, на плейлистах — список).

![Значки зарегистрированных типов файлов](images/file_types.png)

<details>
<summary>Страница, регистрация и форматы</summary>

- **Страница** показывает, зарегистрирован ли плеер, строки действий с кнопками справа — **Зарегистрировать** (после регистрации — **Обновить**), **Выбрать…** для программы по умолчанию и **Удалить** для удаления регистрации, а также форматы, которые регистрирует плеер, с их расширениями и отметкой, открывает ли плеер каждый из них по умолчанию: расширения, которые открывает плеер, выделены ярким, а у формата, часть расширений которого открывает другая программа, показано их число. Кнопка **Выбрать…** доступна после регистрации.
- **Регистрация** даёт каждому формату название в столбце «Тип» Проводника; плеер появляется в пункте **Открыть с помощью** для этих файлов и в разделе **Параметры → Приложения → Приложения по умолчанию**. Программу по умолчанию Windows разрешает выбирать только пользователю: **Выбрать…** открывает этот раздел параметров, а Windows сама предлагает плеер при следующем открытии такого файла. Формат, который ещё не открывает ни одна программа, сразу получает плеер программой по умолчанию. **Удалить** удаляет всё, что записала регистрация; выбор другой программы остаётся прежним.
- **Регистрируемые форматы**: видео MP4 (`.mp4`, `.m4v`), MKV, WebM, AVI (`.avi`, `.divx`), MOV (`.mov`, `.qt`), WMV (`.wmv`, `.asf`), FLV (`.flv`, `.f4v`), MPEG (`.mpg`, `.mpeg`, `.m2v`, `.vob`), TS (`.ts`, `.m2ts`, `.mts`), 3GP (`.3gp`, `.3g2`), OGV и RM (`.rm`, `.rmvb`); звук MP3, FLAC, AAC (`.m4a`, `.aac`), Ogg (`.ogg`, `.oga`), Opus, WAV, WMA, APE, WavPack (`.wv`), MKA, AC3 и DTS; плейлисты M3U (`.m3u`, `.m3u8`).
- **Командная строка**: то же самое установщик и другие сценарии выполняют командами `metalmpv.exe --register` и `metalmpv.exe --unregister`.

</details>

### Настройки

Окно настроек (`F5` или кнопка с шестерёнкой) содержит слева список категорий, справа — параметры выбранной категории, собранные в группы: в каждой строке указано название параметра, под ним пояснение, справа элемент управления; круглая стрелка справа от ползунка возвращает значение по умолчанию. Кнопка **Сбросить** под списком возвращает параметрам окна значения по умолчанию (настройки панели «Видео, звук и субтитры» сбрасываются на панели); запомненные позиции, недавние файлы, режим повтора и положение плейлиста сохраняются.

Звук и вид субтитров настраиваются на [панели видео, звука и субтитров](#панель-видео-звука-и-субтитров) и запоминаются между запусками. Категория **Горячие клавиши** содержит все действия с их клавишами, которые можно изменить (см. [Горячие клавиши](#горячие-клавиши)). При выключении файл на этом заканчивается и воспроизводится следующий в плейлисте. Окончание в последние 15 секунд считается концом файла. В форматах, длительность которых может быть оценочной (MP3, AAC и подобные, в отличие от MKV и MP4), раннее окончание считается нехваткой данных, только если это видно по файлу: на месте недостающих данных нули, как при загрузке, оставляющей под них место, или байтов меньше, чем объявляет заголовок; иначе это конец файла |
| Медиаклавиши | всегда | Всегда (также когда активно другое окно, через системные элементы управления мультимедиа Windows), когда активно окно плеера, или выключены: плеер не перехватывает их, и они достаются Windows и другим программам |

## Проверка обновлений и конфиденциальность

Проверка обновлений необязательна и по умолчанию выключена. При включённом параметре **Проверять при запуске** на странице «Обновления» в настройках программа не чаще раза в сутки запрашивает у GitHub Releases API (`api.github.com`) последний выпуск; кнопка **Проверить сейчас** на той же странице выполняет запрос немедленно. Запрос не содержит ничего, кроме версии программы в заголовке `User-Agent`, и ничего не скачивается и не устанавливается: если есть более новый выпуск, в строке заголовка появляется кнопка с его версией, открывающая страницу выпуска в браузере.

В остальном программа обращается к сети только ради открытого: адрес или плейлист с адресами воспроизводится с их сервера, а при включённых **Логотипах каналов** логотипы, указанные списком IPTV, загружаются с их сайтов (только по HTTPS и никогда из локальной сети; см. настройки). Потоки списка IPTV идут от тех, кто держит его серверы; они видят адрес компьютера и то, что на нём смотрят. `youtube-dl`/yt-dlp не используется.

## Сборка

Требования: Windows 10 или новее, стабильный Rust (цель MSVC, редакция 2024), Visual Studio 2022 Build Tools с компонентом C++ и Python 3. Для `build.py` — [uv](https://docs.astral.sh/uv/).

```
uv run build.py          # target\release\metalmpv.exe и рядом libmpv-2.dll
cargo test
```

<details>
<summary>Как устроена сборка</summary>

`build.py` закрывает `metalmpv.exe`, запущенный из папки `target` проекта (он заблокировал бы файл), при отсутствии загружает libmpv (`tools/get_libmpv.py`) и запускает `cargo build --release`. `tools/get_libmpv.py` скачивает закреплённую сборку libmpv из [shinchiro/mpv-winbuild-cmake](https://github.com/shinchiro/mpv-winbuild-cmake) и автономный `7zr.exe` из 7-Zip для её распаковки, сверяет оба файла с их SHA-256 и помещает в папку `vendor` (в репозиторий она не входит); `build.rs` копирует DLL рядом с исполняемым файлом. Исполняемый файл статически связан со средой выполнения C (`.cargo/config.toml`) и загружает libmpv во время работы, поэтому кроме Windows ему нужна только `libmpv-2.dll`.

</details>

<details>
<summary>Настройка окружения и устройство исходников</summary>

Инструменты устанавливаются через winget:

```
winget install Rustlang.Rustup Microsoft.VisualStudio.2022.BuildTools Python.Python.3.12 astral-sh.uv JRSoftware.InnoSetup
```

Компонент C++ для Build Tools («Разработка классических приложений на C++») выбирается в Visual Studio Installer.

## Установщик и выпуск

Сценарий выпуска собирает исполняемый файл, установщик и портативный архив. Для него нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```
python tools/make_release.py              # libmpv, тесты, сборка, установщик, архив
python tools/make_release.py --no-tests   # то же без cargo test
python tools/make_release.py --install    # затем тихая установка поверх установленной копии
```

<details>
<summary>Порядок выпуска</summary>

Сценарий записывает файлы в папку `dist` и берёт версию из `Cargo.toml`. Сценарий установщика — `tools/setup.iss`; значок установщика записывает команда `metalmpv.exe --export-icon <файл.ico>`.

Выпуски на GitHub собирает workflow **Release** (`.github/workflows/release.yml`). Между выпусками версия в `Cargo.toml` содержит `-dev`. Для выпуска суффикс убирается (после `python tools/notices.py`, если изменился `Cargo.lock`: актуальность уведомлений проверяет тест), изменение фиксируется коммитом `Version X.Y.Z`, а отправка соответствующего тега публикует выпуск с установщиком и портативным архивом; затем версия становится следующей с `-dev`:

```
git tag v0.1.0
git push origin v0.1.0
```

Workflow останавливается, если тег не совпадает с версией в `Cargo.toml` или версия ещё содержит суффикс вроде `-dev`. Ручной запуск (Actions → Release → Run workflow) собирает файлы и прикрепляет их к запуску, не создавая выпуска.

</details>

## Используемые проекты

- [mpv / libmpv](https://mpv.io): декодирование, воспроизведение и вывод изображения;
- [mpv-winbuild-cmake](https://github.com/shinchiro/mpv-winbuild-cmake): поставляемая сборка libmpv для Windows;
- [egui / eframe](https://github.com/emilk/egui): интерфейс и окно;
- [Lofty](https://github.com/Serial-ATA/lofty-rs): обложки из тегов;
- [image](https://github.com/image-rs/image): декодирование обложек;
- [fontdb](https://github.com/RazrFalcon/fontdb): список шрифтов системы;
- [7-Zip](https://www.7-zip.org): распаковка libmpv при сборке;
- [Inno Setup](https://jrsoftware.org/isinfo.php): установщик.
