<p align="center"><a href="README.md">English</a> | <b>Русский</b></p>

Metal Player — видеоплеер для Windows с классической компоновкой: изображение занимает всё окно, под ним полоса перемотки и кнопки с «Воспроизвести» посередине, справа открывается список воспроизведения. Воспроизведением занимается [libmpv](https://mpv.io) — библиотека плеера mpv, поэтому воспроизводятся практически все форматы видео и звука, с аппаратным декодированием там, где его поддерживает видеокарта. Программа рассчитана на быстрое открытие файлов и мгновенную перемотку по ключевым кадрам.

![Metal Player воспроизводит видео, под изображением панель управления](images/screenshot.png)

*Снимок окна версии 0.1.0.*

## Возможности

- **Быстрый запуск**: движок воспроизведения запускается, пока создаётся окно; при повторном запуске первый кадр файла 1080p появляется примерно через 0,4 с после старта программы.
- **Мгновенная перемотка по ключевым кадрам** клавишами-стрелками, точная перемотка и покадровый переход другими клавишами (см. [Горячие клавиши](#горячие-клавиши)); каждая перемотка отображается на экране.
- **Все распространённые форматы**: MP4, MKV, AVI, MOV, WebM, TS, WMV и другие, включая звуковые файлы; субтитры рядом с видео подключаются автоматически.
- **Аппаратное декодирование** (NVDEC, D3D11VA и другие, выбор за libmpv), которое можно отключить в настройках.
- **Список воспроизведения**: файлы, открытые вместе, перетащенные в окно или добавленные кнопкой **+** списка воспроизведения; по желанию — остальные медиафайлы папки открытого файла.
- **Одно окно**: файл, открытый из Проводника при запущенном плеере, воспроизводится в уже открытом окне.
- **Интерфейс на русском или английском**: язык следует языку Windows и меняется в окне «О программе» (`F1`).
- **Портативность**: [портативный архив](#установка) хранит настройки рядом с программой.
- **Конфиденциальность**: обращений к сети нет, кроме необязательной проверки обновлений (см. [Проверка обновлений и конфиденциальность](#проверка-обновлений-и-конфиденциальность)).

## Установка

Установщик и портативный архив находятся на странице [Releases](https://github.com/Fan4Metal/metal_player/releases).

Установщику `Metal_Player_<версия>_Setup.exe` не нужны права администратора: программа устанавливается в `%LOCALAPPDATA%\Programs\Metal Player`. Установленная программа хранит настройки в `%APPDATA%\Metal Player`.

Портативный архив `Metal_Player_<версия>_portable.zip` содержит программу в папке `Metal Player` и работает без установки. В нём также лежит пустой файл `metal_player.ron`. Пока этот файл находится рядом с `metal_player.exe` и папка доступна для записи, настройки хранятся в нём, поэтому программу можно переносить на съёмном носителе. Без этого файла настройки хранятся в `%APPDATA%\Metal Player`, как у установленной программы. Окно «О программе» показывает, где хранятся настройки.

В обоих вариантах есть `libmpv-2.dll` (около 115 МБ в распакованном виде) — движок воспроизведения; файл должен лежать рядом с `metal_player.exe`.

Исполняемые файлы не подписаны, поэтому Windows SmartScreen при первом запуске может предупредить о неизвестном издателе.

## Использование

Файл открывается кнопкой **Открыть файл** (значок извлечения, `Ctrl+O`), перетаскиванием в окно, из Проводника (**Открыть с помощью**) или из командной строки: `metal_player.exe файл.mkv [другие файлы]`. Несколько файлов образуют список воспроизведения; по окончании файла начинается следующий.

У окна собственная строка заголовка: окно перемещается перетаскиванием заголовка, изображения или свободного места панели управления, меняет размер за края и разворачивается двойным щелчком по заголовку. Двойной щелчок по изображению или `Enter` включает полноэкранный режим, в котором остаётся только изображение; панель управления появляется поверх него, пока движется мышь, а указатель скрывается через полсекунды покоя.

На панели управления расположены полоса перемотки (щелчок или перетаскивание переводит воспроизведение в эту точку, время под указателем показывается в подсказке), текущая позиция и длительность, кнопки **Открыть файл**, **Стоп**, **Предыдущий файл**, **Воспроизвести/Пауза**, **Следующий файл**, **Настройки** и **Список воспроизведения**, громкость и кнопка полноэкранного режима. Щелчок правой кнопкой по изображению открывает меню с теми же командами.

Список воспроизведения (`L`) показывает файлы и выделяет текущий; двойной щелчок воспроизводит файл. Кнопки-значки над списком добавляют файлы (**+**), убирают выбранный (**−**, `Delete`), упорядочивают список по имени, числа — по значению (полоски со стрелкой), и очищают его (корзина); их названия видны в подсказках.

### Настройки

Окно настроек (`F5` или кнопка с шестерёнкой) содержит слева список категорий, справа — параметры выбранной категории, сгруппированные в рамках. Кнопка **Сбросить** под списком возвращает всем параметрам значения по умолчанию.

| Категория | Параметр | По умолчанию | Назначение |
|---|---|---|---|
| Общие | Язык интерфейса | как в Windows | Также в окне «О программе» |
| Обновления | Проверять обновления при запуске | выкл. | См. [Проверка обновлений и конфиденциальность](#проверка-обновлений-и-конфиденциальность); **Проверить сейчас** выполняет запрос немедленно |
| Общие | При открытии файла добавлять остальные медиафайлы его папки | выкл. | При открытии одного файла остальные медиафайлы его папки попадают в список |
| Воспроизведение | ← / → | 10 с | Шаг клавиш `←` и `→`, по ключевым кадрам |
| Воспроизведение | Ctrl+← / → | 60 с | Шаг клавиш `Ctrl+←` и `Ctrl+→`, по ключевым кадрам |
| Видео | Аппаратное декодирование (GPU) | вкл. | Декодирование на видеокарте, где это возможно; используемый декодер показан ниже |

Категория **Клавиши** содержит справочный список горячих клавиш. Громкость, окно, видимость и ширина списка воспроизведения сохраняются между запусками.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Пробел` | Воспроизведение / пауза |
| `←` / `→` | Назад / вперёд на короткий шаг (10 с) по ключевым кадрам |
| `Ctrl+←` / `Ctrl+→` | Назад / вперёд на длинный шаг (60 с) по ключевым кадрам |
| `Shift+←` / `Shift+→` | Назад / вперёд на 1 с точно до кадра |
| `,` / `.` (или `D` / `F`) | Предыдущий / следующий кадр |
| `Home` / `End` | Начало / конец файла |
| `↑` / `↓`, колесо мыши | Громкость выше / ниже |
| `M` | Без звука |
| `S` | Стоп |
| `Page Up` / `Page Down` | Предыдущий / следующий файл списка |
| `Enter`, `F11`, двойной щелчок | Полноэкранный режим; `Esc` — выход из него |
| `Ctrl+O` | Открыть файлы |
| `L` | Показать или скрыть список воспроизведения |
| `Delete` | Убрать выбранный файл из списка |
| `F5` | Настройки |
| `F1` | О программе |

Перемотка по ключевым кадрам мгновенна, поскольку перед показом кадра ничего не нужно декодировать; она приходится на ключевой кадр, ближайший к цели, и строка на экране сообщает, куда именно. Точная перемотка декодирует видео от предыдущего ключевого кадра до нужного.

## Проверка обновлений и конфиденциальность

Проверка обновлений необязательна и по умолчанию выключена. При включённом флажке **Проверять обновления при запуске (раз в сутки)** в окне «О программе» программа не чаще раза в сутки запрашивает у GitHub Releases API (`api.github.com`) последний выпуск; кнопка **Проверить сейчас** в том же окне выполняет запрос немедленно. Запрос не содержит ничего, кроме версии программы в заголовке `User-Agent`, и ничего не скачивается и не устанавливается: если есть более новый выпуск, в строке заголовка появляется кнопка с его версией, открывающая страницу выпуска в браузере. В остальном программа к сети не обращается; сетевые возможности libmpv (потоковое воспроизведение, `youtube-dl`) не используются.

## Сборка

Требования: Windows 10 или новее, стабильный Rust (цель MSVC, редакция 2024), Visual Studio 2022 Build Tools с компонентом C++ и Python 3. Для `build.py` — [uv](https://docs.astral.sh/uv/).

```
uv run build.py          # target\release\metal_player.exe и рядом libmpv-2.dll
cargo test
```

`build.py` закрывает `metal_player.exe`, запущенный из папки `target` проекта (он заблокировал бы файл), при отсутствии загружает libmpv (`tools/get_libmpv.py`) и запускает `cargo build --release`. `tools/get_libmpv.py` скачивает закреплённую сборку libmpv из [shinchiro/mpv-winbuild-cmake](https://github.com/shinchiro/mpv-winbuild-cmake) и автономный `7zr.exe` из 7-Zip для её распаковки, сверяет оба файла с их SHA-256 и помещает в папку `vendor` (в репозиторий она не входит); `build.rs` копирует DLL рядом с исполняемым файлом. Исполняемый файл статически связан со средой выполнения C (`.cargo/config.toml`) и загружает libmpv во время работы, поэтому кроме Windows ему нужна только `libmpv-2.dll`.

## Установщик и выпуск

Сценарий выпуска собирает исполняемый файл, установщик и портативный архив. Для него нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```
python tools/make_release.py              # libmpv, тесты, сборка, установщик, архив
python tools/make_release.py --no-tests   # то же без cargo test
python tools/make_release.py --install    # затем тихая установка поверх установленной копии
```

Сценарий записывает файлы в папку `dist` и берёт версию из `Cargo.toml`. Сценарий установщика — `tools/setup.iss`; значок установщика записывает команда `metal_player.exe --export-icon <файл.ico>`.

Выпуски на GitHub собирает workflow **Release** (`.github/workflows/release.yml`). После обновления версии в `Cargo.toml` и коммита отправка соответствующего тега публикует выпуск с установщиком и портативным архивом:

```
git tag v0.1.0
git push origin v0.1.0
```

Workflow останавливается, если тег не совпадает с версией в `Cargo.toml`. Ручной запуск (Actions → Release → Run workflow) собирает файлы и прикрепляет их к запуску, не создавая выпуска.
