<p align="center"><a href="README.md">English</a> | <b>Русский</b></p>

MetalMPV — видеоплеер для Windows с классической компоновкой: изображение занимает всё окно, под ним полоса перемотки и кнопки с «Воспроизвести» посередине, справа открывается плейлист. Воспроизведением занимается [libmpv](https://mpv.io) — библиотека плеера mpv, поэтому воспроизводятся практически все форматы видео и звука, с аппаратным декодированием там, где его поддерживает видеокарта. Программа рассчитана на быстрое открытие файлов и мгновенную перемотку по ключевым кадрам.

![MetalMPV воспроизводит видео, под изображением панель управления](images/screenshot.png)

*Снимок окна версии 0.1.0.*

## Возможности

- **Быстрый запуск**: движок воспроизведения запускается, пока создаётся окно; при повторном запуске первый кадр файла 1080p появляется примерно через 0,4 с после старта программы.
- **Мгновенная перемотка по ключевым кадрам** клавишами-стрелками, точная перемотка и покадровый переход другими клавишами (см. [Горячие клавиши](#горячие-клавиши)); каждая перемотка отображается на экране.
- **Все распространённые форматы**: MP4, MKV, AVI, MOV, WebM, TS, WMV и другие, включая звуковые файлы; субтитры рядом с видео подключаются автоматически.
- **Звуковые дорожки и субтитры** в одном окне у регулятора громкости (`T`), на вкладках или оба списка рядом; субтитры из отдельного файла — через **Загрузить из файла…** или перетаскиванием файла на воспроизводимое видео (см. [Звук и субтитры](#звук-и-субтитры)).
- **Сведения о файле** (`I`): обложка, теги, размер, контейнер, характеристики каждой дорожки и ход воспроизведения в окне, которое остаётся поверх плеера во время воспроизведения; обложка звукового файла занимает место изображения (см. [Сведения о файле](#сведения-о-файле)).
- **Окно под изображение**: 50 %, 100 %, 150 % или 200 % размера видео, наибольшее окно без чёрных полос, окно по размеру изображения или полный экран без чёрных полос (`1`–`6`, `` ` ``).
- **Главы**: метки на полосе перемотки, которые можно отключить, и список под плейлистом для перехода к главе (см. [Главы](#главы)).
- **Повтор A-B, закладки, переход ко времени**: отрезок, воспроизводимый по кругу и сохраняемый в отдельный файл (см. [Повтор A-B](#повтор-a-b)), места в файлах, собранные в меню (см. [Закладки](#закладки)), и время, набранное после `Ctrl+G` (см. [Переход ко времени](#переход-ко-времени)).
- **Аппаратное декодирование** (NVDEC, D3D11VA и другие, выбор за libmpv), которое можно отключить в настройках.
- **Настройки звука**: устройство вывода, каналы (автоматически или раскладка, выбранная вручную), усиление громкости до 200 %, нормализация, выравнивающая громкость, усиление речи, раскладка стерео на 5.1, уровень сабвуфера и срез инфранизких, эквалайзер и передача звука Dolby и DTS на ресивер без декодирования; звук можно сдвинуть относительно изображения клавишами `Ctrl+=` и `Ctrl+-`.
- **Панель видео, звука и субтитров** (`U`): яркость, контраст, насыщенность, оттенок и гамма, масштаб и сдвиг, резкость, шумоподавление и сглаживание полос градиента, принудительные пропорции, чересстрочность, тональная компрессия HDR, поворот и отражение, сохранение кадра; устройство вывода, каналы, усиление, задержка, нормализация, усиление речи и десятиполосный эквалайзер со своими предустановками; вид субтитров со своими заготовками, образец, задержка, чёрные поля и ASS (см. [Панель видео, звука и субтитров](#панель-видео-звука-и-субтитров)).
- **Продолжение просмотра**: фильм при повторном открытии воспроизводится с того места, где был остановлен (см. [Настройки](#настройки)).
- **Плейлист**: файлы, открытые вместе, перетащенные в окно или добавленные кнопкой **+** плейлиста; по желанию — остальные медиафайлы папки открытого файла; поиск, IPTV-плейлисты по группам с логотипами каналов и полосы просмотра каждого файла.
- **Одно окно**: файл, открытый из Проводника при запущенном плеере, воспроизводится в уже открытом окне.
- **Типы файлов**: плеер можно зарегистрировать в Windows для его видео- и аудиоформатов, у каждого из которых свой значок, и выбрать проигрывателем по умолчанию (см. [Типы файлов](#типы-файлов)).
- **Интерфейс на русском или английском**: язык следует языку Windows и меняется в настройках (`F5`).
- **Портативность**: [портативный архив](#установка) хранит настройки рядом с программой.
- **Конфиденциальность**: обращений к сети нет, кроме открытых адресов, необязательной проверки обновлений и логотипов IPTV-каналов, которые можно выключить (см. [Проверка обновлений и конфиденциальность](#проверка-обновлений-и-конфиденциальность)).

## Установка

Установщик и портативный архив находятся на странице [Releases](https://github.com/Fan4Metal/metalmpv/releases).

Установщику `MetalMPV_<версия>_Setup.exe` не нужны права администратора: программа устанавливается в `%LOCALAPPDATA%\Programs\MetalMPV`. Установленная программа хранит настройки в `%APPDATA%\MetalMPV`. Задача установщика **Типы файлов**, включённая по умолчанию, регистрирует плеер для его форматов (см. [Типы файлов](#типы-файлов)); на последней странице установщик предлагает открыть параметры Windows, чтобы выбрать плеер проигрывателем по умолчанию. При удалении программы регистрация удаляется; настройки в `%APPDATA%\MetalMPV` (вместе с запомненными позициями и логотипами каналов) сохраняются.

Портативный архив `MetalMPV_<версия>_portable.zip` содержит программу в папке `MetalMPV` и работает без установки. В нём также лежит пустой файл `metalmpv.ron`. Пока этот файл находится рядом с `metalmpv.exe` и папка доступна для записи, настройки хранятся в нём, поэтому программу можно переносить на съёмном носителе. Без этого файла настройки хранятся в `%APPDATA%\MetalMPV`, как у установленной программы. Окно «О программе» показывает, где хранятся настройки. Рядом с файлом настроек лежит его копия, сделанная при каждом запуске (`app.ron.bak` или `metalmpv.ron.bak`); повреждённый файл настроек, например при отключении питания во время записи, заменяется этой копией.

В обоих вариантах есть `libmpv-2.dll` (около 115 МБ в распакованном виде) — движок воспроизведения; файл должен лежать рядом с `metalmpv.exe`.

Исполняемые файлы не подписаны, поэтому Windows SmartScreen при первом запуске может предупредить о неизвестном издателе.

## Использование

Файл открывается кнопкой **Открыть файл** (значок извлечения, `Ctrl+O`), перетаскиванием в окно, из Проводника (**Открыть с помощью**) или из командной строки: `metalmpv.exe файл.mkv [другие файлы]`. Несколько файлов образуют плейлист; по окончании файла начинается следующий. Файлы, перетащенные в окно или в плейлист, добавляются в конец плейлиста и сразу воспроизводятся, только если плейлист был пуст или ничего не воспроизводится (файл, который уже есть в плейлисте, тогда воспроизводится со своего места; о добавленных при скрытом плейлисте сообщает экранное сообщение); файл субтитров, перетащенный вместе с видео, когда ничего не воспроизводится, подключается к этому видео. Плейлист M3U или M3U8, открытый, перетащенный или переданный в командной строке, заменяется своими записями (относительные пути отсчитываются от папки плейлиста, адреса `file:///` считаются путями, а файл `.m3u` не в UTF-8 читается в кодировке системы, как его записывали старые плееры; плейлист потока HLS, с тегами `#EXT-X-`, воспроизводится как один поток); так же, как только mpv его прочитает, заменяется плейлист по адресу (`http://…/list.m3u`) и плейлист, указанный внутри другого. Строки `#EXTINF` списка IPTV задают названия записей: плейлист, заголовок окна и сохранённые кадры показывают название канала вместо имени файла потока, подсказка записи — её группу, а рядом с названием показывается логотип канала (`tvg-logo`; см. **Логотипы каналов** в настройках); **Сохранить плейлист** записывает названия, логотипы и группы обратно. `Ctrl+U` или пункт **Открыть адрес…** контекстного меню воспроизводит прямую ссылку на видео или поток (http, https, rtsp, rtmp, udp и другие; адрес в командной строке тоже принимается); страницы YouTube и других сайтов не поддерживаются, поскольку плеер не использует yt-dlp. Пока ничего не воспроизводится, стартовый экран показывает под заголовком НЕДАВНИЕ, по центру под подсказкой, последние воспроизведённые файлы (до восьми, сколько позволяет высота окна; остальные из тридцати запомненных прокручиваются на их месте); щелчок воспроизводит файл, а **Очистить список** очищает список, как и **Забыть всё** в разделе «Продолжение просмотра» настроек. При выключенной настройке **Запоминать недавние файлы** файлы не запоминаются. Кнопка программы на панели задач показывает позицию как индикатор выполнения (жёлтый на паузе), а под её миниатюрой есть кнопки **Предыдущий файл**, **Воспроизвести**/**Пауза** и **Следующий файл**. Пока воспроизводится видео, экран не гаснет и компьютер не засыпает; пока звучит только звук, компьютер не засыпает, а на паузе и после окончания воспроизведения снова действуют настройки электропитания Windows.

У окна собственная строка заголовка: окно перемещается перетаскиванием заголовка, изображения или свободного места панели управления, меняет размер за края и разворачивается двойным щелчком по заголовку. Двойной щелчок по изображению или `Enter` включает полноэкранный режим, в котором остаётся только изображение; панель управления внизу и название файла вверху появляются поверх него независимо друг от друга, каждая — пока указатель находится у её края, а сам указатель скрывается через полсекунды покоя вдали от них. Полосу с названием можно отключить, а прозрачность обеих панелей задаётся в настройках. `L` или средний щелчок показывает плейлист поверх правой части экрана, на всю его высоту; ширина меняется перетаскиванием левого края; `Esc` или та же клавиша скрывает его, как и выход из полноэкранного режима.

`1`, `2`, `3` и `4` подгоняют окно так, чтобы изображение показывалось в 50 %, 100 %, 150 % или 200 % размера видео (при 100 % пиксель видео приходится на пиксель экрана), `5` делает окно наибольшим из помещающихся на экране, в пропорциях изображения, так что чёрных полос нет, а `` ` `` (клавиша слева от `1`) подгоняет окно под показанное изображение, убирая чёрные полосы. Развёрнутое окно сначала восстанавливается, полноэкранный режим выключается; окно, которое не поместилось бы на экране, уменьшается с сохранением пропорций изображения и по возможности сохраняет своё положение по центру. `6` включает полноэкранный режим, в котором изображение увеличено до заполнения экрана с обрезкой краёв, так что чёрных полос нет; повторное нажатие `6` снова показывает изображение целиком, с чёрными полосами, не выходя из полноэкранного режима; выход из полноэкранного режима тоже возвращает изображение целиком. Те же команды собраны в подменю **Масштаб** контекстного меню изображения. Интерфейс имеет четыре вида, которые выбираются в подменю **Интерфейс** контекстного меню и переключаются по кругу клавишей `8`: **Полный** (строка заголовка и панель управления в две строки), **Без заголовка**, **Компактный** (без строки заголовка, панель управления в одну строку: слева воспроизведение, предыдущий и следующий файлы, время и полоса перемотки, справа громкость и остальные кнопки; открытие файла и остановка остаются в контекстном меню и на клавишах, а в узком окне менее нужные кнопки скрываются, чтобы полоса перемотки сохранила место) и **Только видео**. Без строки заголовка она вместе с кнопками окна появляется поверх верхнего края изображения, пока там находится указатель. Вид сохраняется между запусками (выбирается также на странице «Общие» настроек); в полноэкранном режиме при компактном виде панель управления тоже компактная. При смене вида окно увеличивается или уменьшается на разницу, так что изображение остаётся на прежнем месте и того же размера; развёрнутое или полноэкранное окно сохраняет размер и подгоняется после восстановления. `7` (или пункт **Только видео**) скрывает строку заголовка, панель управления и плейлист, оставляя только изображение; строка заголовка появляется поверх его верхнего края, а панель управления выбранного вида — поверх нижнего, пока указатель находится у края, и окно по-прежнему перемещается перетаскиванием изображения и меняет размер за края. Повторное `7`, `Esc` или пункт **Вернуть интерфейс** в начале контекстного меню возвращает вид, показанный до этого (полный, если программа запущена в режиме «только видео»); то же делает запрос плейлиста (`L`, средний щелчок, контекстное меню), который при этом показывается.

На панели управления расположены полоса перемотки (щелчок или перетаскивание переводит воспроизведение в эту точку, время под указателем показывается в подсказке), время (щелчок по нему переключает текущую позицию с длительностью, только текущую позицию и оставшееся время; выбор сохраняется), кнопки **Открыть файл**, **Стоп**, **Предыдущий файл**, **Воспроизвести/Пауза**, **Следующий файл**, **Настройки** и **Плейлист**, кнопки панели «Видео, звук и субтитры» и дорожек, кнопка звука с громкостью и кнопка полноэкранного режима. Щелчок правой кнопкой по изображению открывает меню с теми же командами.

Плейлист (`L`) показывает файлы, выделяет текущий и прокручивается к нему, когда тот меняется. Щелчок выбирает запись, `Ctrl`+щелчок добавляет запись к выбору или убирает из него, `Shift`+щелчок выбирает диапазон показанных записей (скрытые поиском или в свёрнутой группе в выбор не входят, как и при **Выделить все**); двойной щелчок воспроизводит файл. Выбранные записи перемещаются перетаскиванием (линия показывает, куда они встанут; не во время поиска и не в группах). Правая кнопка открывает меню записи: **Воспроизвести**, **Показать в папке**, **Копировать путь** (пути всех выбранных записей), **Выделить все** и **Убрать из плейлиста**. Тонкая линия под записью показывает, сколько просмотрено, а галочка справа отмечает файл, досмотренный до конца (для файлов от пяти минут, пока включено **Продолжать с места остановки**); пункт **Показывать полосы просмотра** в меню записи отключает и включает линии (галочки остаются), выбор запоминается. Записи IPTV-плейлиста с группами (`group-title`) показываются под своими группами, которые сворачиваются щелчком по заголовку; меню группы сворачивает или разворачивает их все, а пункт **Показывать группы** в меню записи или группы отключает и включает это, выбор запоминается. Лупа справа от кнопок или `Ctrl+F` показывает поле поиска: плейлист тогда показывает записи, в названии которых есть набранный текст, `Enter` воспроизводит первую из них, а `Esc` в поле закрывает его; вне поля `Esc` действует как обычно. Кнопки-значки над плейлистом добавляют файлы (**+**), убирают выбранные (**−**, `Delete`), упорядочивают плейлист по имени, числа — по значению (полоски со стрелкой), очищают его (корзина), сохраняют в плейлист M3U8 (стрелка в лоток), а после черты перемешивают (скрещённые стрелки; текущий файл продолжает играть и встаёт первым); их названия видны в подсказках. Кнопка с петлёй рядом с ней, `R` или подменю **Повтор** контекстного меню переключает режим повтора, который запоминается: выключен, файл (воспроизводится снова без паузы) или плейлист (после последнего файла — первый; **Следующий** и **Предыдущий** ходят по кругу).

Кнопка в правом конце ряда кнопок плейлиста (окно со стрелкой) или пункт **Плейлист в отдельном окне** контекстного меню изображения переносит плейлист в отдельное окно и обратно. Это окно, как и окно плеера, без рамки Windows: у него своя строка заголовка (за неё окно перетаскивается, справа — кнопка закрытия), а размер меняется за края; у него нет кнопки на панели задач, оно находится поверх плеера и сворачивается вместе с ним; в первый раз оно встаёт у правого края плеера во всю его высоту. Поднесённое к краю плеера, окно притягивается к нему и выравнивается по верху, низу или боковому краю плеера; прилипнув к краю, оно перемещается вместе с плеером и следует за изменением его размера (кроме развёрнутого и полноэкранного режимов). В полноэкранном режиме окно скрыто, если оно закрывало бы экран плеера. Клавиши плеера в нём работают, кроме `Esc`, которая закрывает это окно. Положение и размер окна запоминаются.

### Панель видео, звука и субтитров

`U` (также `F7`), кнопка с ползунками слева от кнопки дорожек на панели управления или пункт **Видео, звук и субтитры…** контекстного меню изображения открывает панель над этой кнопкой, как у кнопки дорожек (в правом нижнем углу, если показано только изображение); её высота одна для всех вкладок, а если окно для неё слишком низкое, она занимает высоту над кнопкой и вкладки прокручиваются под заголовком. Воспроизведение и клавиши при этом продолжают работать; щелчок вне панели, повторное нажатие кнопки, `U`, `F7` или `Esc` закрывает её. В её заголовке — вкладки **Видео**, **Звук** и **Субтитры** (открытая подчёркнута; на вкладках щелчок по заголовку раздела сворачивает или разворачивает его, и панель запоминает это между запусками) и фотоаппарат — **Сохранить кадр** (`Ctrl+E`, также в контекстном меню): он сохраняет кадр на экране в том виде, в каком он декодирован, без субтитров, в формате PNG или JPG (см. «Видео» в настройках) с названием файла и позицией в папку «Изображения\MetalMPV» или выбранную; правый щелчок по нему предлагает **Открыть папку**.

Значения задаются ползунками, дорожка которых подсвечивается от исходной точки до ручки, так что изменение видно сразу; значение рядом с ползунком можно также перетащить или ввести, оно выделено акцентным цветом, пока отличается от исходного, а двойной щелчок по ползунку или круговая стрелка рядом возвращает исходное. Включение и выключение — переключатели. Подсказка каждого параметра объясняет, как он действует: на какие субтитры, на процессоре или на видеокарте, запоминается ли между запусками.

На вкладке «Видео» ползунки задают яркость, контраст, насыщенность, оттенок и гамму от −100 до 100; масштаб от 50 до 400 %, а под ним — навигатор: кадр в уменьшенном виде с рамкой вокруг части, видимой на экране; рамку можно перетащить или поставить щелчком, сдвигая изображение (до ±50 % в каждую сторону; числа рядом со **Сдвигом** принимают значение с клавиатуры, двойной щелчок по навигатору возвращает кадр в центр), а **Навигатор на изображении** показывает то же в правом нижнем углу изображения, пока оно увеличено больше окна (выше места, где поверх изображения появляется панель управления); резкость (адаптивная резкость AMD, CAS) и шумоподавление (от 0 — выключено — до 100 %; 40 % — обычная сила FFmpeg, больше — размывает). Сглаживание полос градиента убирает ступеньки на небе и в тёмных сценах. Пропорции берутся из файла или задаются принудительно: 4:3, 16:9, 16:10, 1.85:1, 2.35:1 или 2.39:1 (также в подменю **Пропорции** контекстного меню изображения). Чересстрочность сшивает чересстрочные кадры, как в ТВ-записях, в целые: автоматически для кадров, помеченных как чересстрочные (по умолчанию), всегда или никогда. **HDR на SDR** выбирает, как HDR-изображение приводится к обычному экрану: автоматически, BT.2390 (по стандарту), Hable (кинематографичный), Möbius (яркий), Reinhard (мягкий) или обрезкой. Ряд из четырёх кнопок-значков, названия которых видны в подсказках, поворачивает изображение влево или вправо на 90°, переворачивает его вертикально или отражает зеркально (включённые отражения подсвечены). Резкость, шумоподавление и отражения — фильтры FFmpeg, их выполняет процессор (пока включён любой из них, при аппаратном декодировании каждый кадр копируется для них обратно в память); остальное выполняет видеокарта. Настройки действуют для всех файлов до закрытия программы, а при включённом **Запоминать** — и между запусками; **Сбросить всё** возвращает исходные значения.

Вкладка «Звук» (её открывает и действие «Эквалайзер», у которого нет клавиши по умолчанию) начинается с того, что сейчас играет: каналы дорожки нарисованы динамиками вокруг слушателя (а если звук сводится для устройства в другие каналы — стрелка к значку каналов устройства), рядом — формат так, как его называет декодер (E-AC3 Atmos, DTS-HD MA и подобные; полное имя кодека в подсказке), каналы, частота дискретизации и текущий битрейт, а также что получает устройство (частота, каналы и формат отсчётов либо битовый поток, передаваемый на ресивер). Далее она содержит устройство вывода (пока выбранное отключено, звук идёт через устройство Windows по умолчанию); каналы («Авто» следует настройке устройства в Windows; моно, стерео, 5.1 или 7.1 сводят звук в эту раскладку); **Ресивер** — передачу звука Dolby и DTS в сжатом виде, чтобы его декодировал ресивер (по S/PDIF — AC3 и DTS, по HDMI — также E-AC3, DTS-HD и TrueHD; громкость, нормализация, эквалайзер и каналы плеера на него не действуют, Windows отдаёт устройство только плееру, а формат, который устройство не принимает, декодируется как обычно); усиление громкости (до 130, 150 или 200 %; на громких местах возможны искажения); задержку звука относительно изображения (ползунок ±5 с; клавишами можно дальше, между запусками не запоминается); нормализацию (фильтр FFmpeg `dynaudnorm`: тихие диалоги громче, громкие сцены тише; её **Сила** — мягкая, средняя или сильная — поднимает тихие места до 3, 5 или 10 раз, сильная подстраивается быстрее всех) и **Усилить речь** — подъём голоса над музыкой: в стереодорожке фильтром FFmpeg для диалогов, в дорожке 5.1 и больше — подъёмом центрального канала, моно остаётся как есть; его **Сила**, от +1 до +20 дБ (по умолчанию +4), — насколько голос громче остального: центральный канал поднимается до 12 дБ, сильнее — вместо этого приглушаются остальные каналы, чтобы громкий голос не хрипел; в стерео сначала с той же силой работает фильтр для диалогов (до своего предела на 12 дБ); **Стерео в 5.1** — раскладка стереодорожки на 5.1 для акустики, которая его принимает (фильтр FFmpeg `surround`: общее для обеих сторон, в основном голос, уходит в центр, различия — в тыловые, низкие частоты — на сабвуфер; «Усилить речь» тогда поднимает этот центр), недоступна, пока «Каналы» сводят звук в моно или стерео. Настройки функции видны, только пока она включена. Под ней **Сабвуфер до** задаёт частоту, ниже которой звук уходит на сабвуфер (40–200 Гц, по умолчанию 80 — разделение, принятое в кинотеатрах; выше неё он затухает до удвоенной частоты), а **Басы только в сабвуфер** убирает низкие частоты из остальных колонок, а не только дублирует их в сабвуфер, — для небольших фронтальных колонок. Раздел **Сабвуфер** содержит его **Уровень** в дБ (от −20 до +10): для дорожки 5.1 или 7.1 — относительно уровня в самой дорожке, для «Стерео в 5.1» — относительно стандарта 5.1, на 10 дБ ниже остальных каналов, поскольку ресиверы воспроизводят этот канал на 10 дБ громче; и **Срез инфранизких**, убирающий во всех каналах то, что ниже заданной частоты (15–40 Гц, по умолчанию 25; 24 дБ на октаву): сабвуфер это почти не воспроизводит, но его диффузор доходит до предела хода и бас булькает, а в фильмах с глубоким басом такого много. Ниже — десятиполосный эквалайзер от 31 Гц до 16 кГц, ±12 дБ на полосу (двойной щелчок или круговая стрелка под полосой возвращает 0), со шкалой ±12 дБ, линией 0 дБ и кривой через полосы; переключатель включает его, а список рядом содержит предустановки «Ровно», «Рок», «Поп», «Джаз», «Классика», «Басы», «Голос» и «Высокие». Плюс рядом со списком сохраняет полосы под названием, которое вводится в появившейся строке (Enter сохраняет, Esc отменяет; с тем же названием заменяется); такие наборы идут в списке после предустановок, под заголовком «Мои», не более двадцати, а корзина удаляет выбранный. Всё, кроме задержки, запоминается между запусками; эквалайзер, нормализация и усиление речи не действуют на звук, передаваемый на ресивер без декодирования.

Вкладка «Субтитры» начинается с заготовок: мягкие с тенью (по умолчанию), классические как в mpv, с тонкой обводкой, жирные с толстой обводкой, только тень без обводки, кремовые, бледно-мятные, на тёмной подложке и тёмные на светлой подложке; каждая задаёт цвета, обводку, тень, жирность и подложку, а шрифт, размер и высоту оставляет как есть (после изменения любого из этих параметров в списке значится «Другой»). Плюс рядом со списком так же сохраняет весь вид, включая шрифт, размер и высоту, под названием; такие заготовки идут после готовых, под заголовком «Мои», не более двадцати, а корзина удаляет выбранную. Они запоминаются между запусками, и кнопка «Сбросить» в настройках их сохраняет. Под списком крупный образец примерно показывает вид субтитров — шрифтом интерфейса и постоянного размера, на фоне от тёмного к светлому. Ниже вкладка задаёт шрифт и размер (всех субтитров, включая ASS), жирное начертание, цвет букв и обводки, толщину обводки, тень, полупрозрачную подложку под каждой строкой вместо обводки (цвета обводки; толщина становится её полями), высоту субтитров на изображении, **В чёрных полях** (по умолчанию включено: если у изображения есть чёрные поля, субтитры, в том числе ASS, идут в них; выключено — поверх изображения), **Стиль и для ASS** (шрифт, цвета и обводка заменяют и стили субтитров ASS, надписи и эффекты в которых тогда теряют свой вид) и их задержку (ползунок ±5 с, между запусками не запоминается). Под задержкой шкала времени показывает отрезок вокруг текущей позиции с вертикальной линией посередине; реплики субтитров из отдельного файла (SRT, WebVTT, ASS) показаны на нём блоками со сдвигом на задержку. Перетаскивание блоков задаёт задержку, а начало реплики ненадолго задерживается на линии позиции; так пауза там, где звучит реплика, и её блок на линии подгоняют субтитры к речи. Кнопки-стрелки по краям ставят на текущий момент реплику до или после показанной (`Ctrl+Shift+←` и `Ctrl+Shift+→`, для любых субтитров), а − и + меняют длину отрезка, от 10 с до 5 мин 20 с. **Сбросить всё** возвращает исходный вид. Иначе размер и высота действуют на все субтитры, шрифт и цвета — на текстовые (SRT и подобные). Всё, кроме задержки, запоминается между запусками.

### Главы

Если в файле есть главы, полоса перемотки разделена разрывами в начале каждой из них, а подсказка над полосой называет главу под указателем. Метки отключаются и включаются в подменю **Главы** контекстного меню изображения или в настройках (**Воспроизведение**). Под плейлистом раздел **Главы** перечисляет их с временем начала и выделяет текущую; щелчок переходит к главе, щелчок по заголовку сворачивает раздел. Тот же список есть в подменю **Главы**. Переход отображается на экране с номером и названием главы.

### Переход ко времени

`Ctrl+G` или пункт **Перейти ко времени…** контекстного меню изображения открывает окно, в поле которого стоит текущая позиция, выделенная так, что введённое время её заменяет. Поле принимает `1:23:45`, `83:20`, число секунд (`5000`), дробную часть после точки или запятой (`1:23,5`), долю файла (`50%`) или сдвиг от текущей позиции (`+30`, `-1:00`, `+10%`); под полем окно показывает время, которое получается, и его долю в файле, либо сообщает, что текст не является временем в этом файле. `Enter` или **Перейти** переходит туда с точностью до кадра; время после конца файла ведёт к концу.

### Закладки

`Ctrl+B` или пункт **Закладки → Добавить закладку здесь** контекстного меню изображения запоминает текущий файл и позицию. Подменю **Закладки** перечисляет их, последние сверху, каждую — именем файла и временем, с тонкой линией под ней, показывающей место закладки в файле; закладки текущего файла отмечены. Щелчок переходит к закладке: в текущем файле сразу, иначе её файл воспроизводится с этого места (его запись в плейлисте или открытый файл); крестик рядом удаляет закладку, а **Удалить все закладки** — все. Между запусками хранится до 30 закладок, старые уступают место; сброс настроек их не затрагивает.

### Повтор A-B

`[` отмечает начало отрезка в текущей позиции, а `]` — его конец; после этого воспроизведение каждый раз по достижении конца возвращается к началу, пока `\` не выключит повтор. Конец, отмеченный без начала, повторяет отрезок от начала файла, а конец раньше начала меняет точки местами. Точки показываются жёлтыми рисками на полосе перемотки, отрезок между ними подсвечивается, экранное сообщение называет их с точностью до десятой доли секунды, а подменю **Повтор A-B** контекстного меню изображения делает то же самое. Точки относятся к файлу: другой файл начинается без них.

`Ctrl+Shift+S` или пункт **Сохранить фрагмент…** того же подменю сохраняет отрезок между точками в отдельный файл, пока воспроизведение продолжается. В окне указывается файл (MP4 рядом с исходным, а для адреса — в папке сохранённых кадров, со временем в имени; **…** выбирает другой; имя без папки сохраняется в ту же папку, а к имени без `.mp4`, `.mkv` или `.mov` добавляется `.mp4`; воспроизводимый файл и уже существующий не перезаписываются, кроме файла, замену которого подтвердил диалог **…**) и параметры кодирования: H.264 или HEVC, на процессоре (x264, x265) или видеокарте NVIDIA (NVENC), качество (по умолчанию 22; меньше — лучше и крупнее файл) и, при желании, показанные субтитры, впечатанные в изображение в их стиле; звук — текущая дорожка, в AAC; задержки звука и субтитров и устранение чересстрочности берутся из плеера. Отрезок вырезается точно по точкам. Затем показываются полоса прогресса и кнопки **Отмена** и **Скрыть**: скрытое окно не мешает пользоваться плеером, пока сохранение идёт, а `Ctrl+Shift+S` показывает его снова; экранное сообщение называет сохранённый файл или причину неудачи (для NVENC нужна видеокарта NVIDIA). Выбор запоминается.

### Звук и субтитры

Кнопка с облачком речи слева от громкости (`T`) открывает окно со звуковыми дорожками и субтитрами файла на двух вкладках; кнопка справа от вкладок показывает их рядом в две колонки, а та же кнопка в этом виде возвращает вкладки (выбор запоминается между запусками). У каждой дорожки первым указан язык, за ним через тире название дорожки («Русский — Superbit»); под ними плашки показывают формат, число каналов и пометки «внешние», «принудительные», «по умолчанию». Длинный список прокручивается. Выбор применяется сразу, а окно остаётся открытым, поэтому звук и субтитры можно сменить за один раз; как и при панели видео, звука и субтитров, которую оно сменяет на том же месте, воспроизведение и клавиши продолжают работать, а щелчок вне окна, повторное нажатие кнопки, `T` или `Esc` закрывает его. **Загрузить из файла…** под субтитрами подключает субтитры из отдельного файла (SRT, ASS, SSA, VobSub, PGS, WebVTT); так же подключается файл субтитров, перетащенный на воспроизводимое видео. Субтитры с тем же именем, что у видео, рядом с ним подключаются сами. Те же списки есть в контекстном меню изображения, а каждая смена отображается на экране.

### Сведения о файле

Клавиша `I`, кнопка **i** в строке заголовка или пункт **Сведения о файле** контекстного меню изображения открывает окно поверх плеера; пока оно открыто, воспроизведение продолжается и клавиши работают, а `I` или `Esc` закрывает его. Вверху показаны обложка, название, исполнитель и альбом; щелчок по обложке показывает её в размере, который позволяет окно. Под ними в рядах чипов — главное, чтобы не нужно было прокручивать: файл (формат, размер, длительность, общий битрейт), изображение (кодек, размер кадра, соотношение сторон, частота кадров, разрядность, HDR, битрейт) и звук — по чипу на каждую звуковую дорожку (кодек, каналы, язык), играющая обведена; щелчок по чипу звуковой дорожки включает её, а если дорожек больше четырёх, остальные свёрнуты в один чип, который перечисляет их в подсказке. Чип субтитров называет их язык и число. Подсказка каждого чипа говорит больше: название контейнера, полное имя кодека и профиль, название и характеристики дорожки. Чипы цветные: формат — цветом значка его типа файлов, изображение, звук и субтитры — каждый своим оттенком. Канал списка IPTV показывается с названием и группой из списка, а вместо обложки — его логотип, когда он загружен. Ниже идут разделы, которые сворачиваются щелчком по заголовку и копируются текстом из его контекстного меню. Файл: имя, папка, размер, контейнер, длительность, общий битрейт, число глав, программа, записавшая файл Matroska, и время записи, даты файла; щелчок по папке показывает файл в Проводнике. Воспроизведение, обновляемое каждую секунду: текущий битрейт с графиком за последнюю минуту, частота показа кадров рядом с частотой экрана, пропущенные кадры, что получает звуковое устройство (в том числе формат, передаваемый без декодирования) и для потока — объём данных, прочитанных наперёд. Теги: распространённые — первыми и с названиями на языке интерфейса, остальные — так, как они названы в файле; длинный тег сокращается, а ссылка **ещё** показывает его целиком. Дорожки, сгруппированные на видео, аудио и субтитры, играющая отмечена точкой; у каждой в одной строке указаны формат, размер кадра, частота кадров, разрядность, HDR, число каналов, частота дискретизации и битрейт; формат звуковой дорожки уточняется, когда его сообщает декодер (DTS-HD MA, DTS:X, E-AC3 Atmos, TrueHD Atmos, HE-AAC). Щелчок по дорожке раскрывает подробности, а показываемое видео раскрыто сразу: профиль и уровень кодека, соотношение сторон, раскладка каналов, битрейт и размер потока (из статистики, которую mkvmerge записывает в файл Matroska, иначе примерный), число кадров, признаки и теги дорожки, а для показываемого видео также цветовая субдискретизация, развёртка, диапазон цветов, основные цвета, передаточная функция и матрица, формат HDR и уровни яркости с данными дисплея мастеринга, способ декодирования (аппаратный или программный). Любое значение можно выделить, а его контекстное меню копирует значение или всю строку. Справа в строке названия расположены две кнопки-значка, названия которых видны в подсказках: **Копировать всё** (два листа) помещает все сведения в буфер обмена текстом, значения выровнены в столбец, и на мгновение показывает галочку, а **Сохранить обложку…** (стрелка в лоток) сохраняет изображение в том виде, в каком оно хранится. Окно находится у правого верхнего угла плеера, в том числе после изменения размера окна плеера. Его нижний край можно перетащить, чтобы сделать окно выше или ниже.

Обложка берётся из тегов файла (MP3, FLAC, OGG, Opus, M4A, MP4, WAV, APE и другие) или из его вложений (MKV, MKA, WebM); для звукового файла без обложки используется изображение с именем `cover`, `folder` или `front` рядом с ним. Пока воспроизводится звуковой файл, его обложка занимает место изображения, а под ней указаны название, исполнитель и альбом.

### Типы файлов

Страница **Типы файлов** в настройках (`F5`) показывает, зарегистрирован ли плеер, строки действий с кнопками справа — **Зарегистрировать** (после регистрации — **Обновить**), **Выбрать…** для программы по умолчанию и **Удалить** для удаления регистрации, а также форматы, которые регистрирует плеер, с их расширениями и отметкой, открывает ли плеер каждый из них по умолчанию: расширения, которые открывает плеер, выделены ярким, а у формата, часть расширений которого открывает другая программа, показано их число. Кнопка **Выбрать…** доступна после регистрации. Установщик тоже регистрирует форматы.

![Значки зарегистрированных типов файлов](images/file_types.png)

Регистрация выполняется для текущего пользователя и не требует прав администратора. Каждый формат получает собственный тип со значком (свой оттенок для каждого семейства форматов, на видео — знак воспроизведения, на звуке — нота, на плейлистах — список) и названием в столбце «Тип» Проводника; плеер появляется в пункте **Открыть с помощью** для этих файлов и в разделе **Параметры → Приложения → Приложения по умолчанию**. Программу по умолчанию Windows разрешает выбирать только пользователю: **Выбрать…** открывает этот раздел параметров, а Windows сама предлагает плеер при следующем открытии такого файла. Формат, который ещё не открывает ни одна программа, сразу получает плеер программой по умолчанию. **Удалить** удаляет всё, что записала регистрация; выбор другой программы остаётся прежним.

Регистрируемые форматы: видео MP4 (`.mp4`, `.m4v`), MKV, WebM, AVI (`.avi`, `.divx`), MOV (`.mov`, `.qt`), WMV (`.wmv`, `.asf`), FLV (`.flv`, `.f4v`), MPEG (`.mpg`, `.mpeg`, `.m2v`, `.vob`), TS (`.ts`, `.m2ts`, `.mts`), 3GP (`.3gp`, `.3g2`), OGV и RM (`.rm`, `.rmvb`); звук MP3, FLAC, AAC (`.m4a`, `.aac`), Ogg (`.ogg`, `.oga`), Opus, WAV, WMA, APE, WavPack (`.wv`), MKA, AC3 и DTS; плейлисты M3U (`.m3u`, `.m3u8`).

То же самое установщик и другие сценарии выполняют из командной строки: `metalmpv.exe --register` и `metalmpv.exe --unregister`.

Громкость, окно, видимость и ширина плейлиста сохраняются между запусками.

## Горячие клавиши

Ниже приведены клавиши по умолчанию. В настройках категория **Горячие клавиши** перечисляет действия по группам, каждое со своими клавишами: щелчок по клавише ждёт нажатия сочетания (или кнопки мыши «назад» либо «вперёд», при желании с `Ctrl`, `Alt` или `Shift`), которое займёт её место, **+** добавляет ещё одно, крестик удаляет клавишу, а `Esc` отменяет выбор. Сочетание, принадлежавшее другому действию, переходит от него, о чём сообщается на странице, рядом с кнопкой **Отменить**. Поле поиска над группами оставляет действия, в названии или клавишах которых есть введённый текст. Нескольким действиям без клавиши по умолчанию её можно назначить: «Стоп», «Загрузить субтитры из файла», «Повтор A-B: начало, конец, выключить» (одна клавиша для всех трёх по очереди), «Эквалайзер», «Сбросить эквалайзер (ровный, выкл.)», «Сбросить вид субтитров», «Метки глав на полосе перемотки», «Время: оба, прошло, осталось», «Перемешать плейлист», «Сортировать плейлист», «Очистить плейлист», «Показать файл в папке», «Открыть папку сохранённых кадров», «Сохранить обложку…», «Плейлист в отдельном окне / в окне плеера», «Группы IPTV в плейлисте», «Полосы просмотра в плейлисте», «Свернуть окно», «Развернуть / восстановить окно» и «Закрыть программу». **Сбросить клавиши** возвращает все клавиши по умолчанию. Меню и подсказки показывают клавиши в том виде, в каком они назначены. Колесо мыши, двойной и средний щелчки и медиаклавиши остаются такими, как описано; `Ctrl+V` и `Shift+Insert` выбрать нельзя, а `Ctrl+Insert` считается сочетанием `Ctrl+C`.

## Проверка обновлений и конфиденциальность

Проверка обновлений необязательна и по умолчанию выключена. При включённом параметре **Проверять при запуске** на странице «Обновления» в настройках программа не чаще раза в сутки запрашивает у GitHub Releases API (`api.github.com`) последний выпуск; кнопка **Проверить сейчас** на той же странице выполняет запрос немедленно. Запрос не содержит ничего, кроме версии программы в заголовке `User-Agent`, и ничего не скачивается и не устанавливается: если есть более новый выпуск, в строке заголовка появляется кнопка с его версией, открывающая страницу выпуска в браузере. В остальном программа обращается к сети только ради открытого: адрес или плейлист с адресами воспроизводится с их сервера, а при включённых **Логотипах каналов** логотипы, указанные списком IPTV, загружаются с их сайтов (только по HTTPS и никогда из локальной сети; см. настройки). Потоки списка IPTV идут от тех, кто держит его серверы; они видят адрес компьютера и то, что на нём смотрят. `youtube-dl`/yt-dlp не используется.

## Сборка

Требования: Windows 10 или новее, стабильный Rust (цель MSVC, редакция 2024), Visual Studio 2022 Build Tools с компонентом C++ и Python 3. Для `build.py` — [uv](https://docs.astral.sh/uv/).

```
uv run build.py          # target\release\metalmpv.exe и рядом libmpv-2.dll
cargo test
```

`build.py` закрывает `metalmpv.exe`, запущенный из папки `target` проекта (он заблокировал бы файл), при отсутствии загружает libmpv (`tools/get_libmpv.py`) и запускает `cargo build --release`. `tools/get_libmpv.py` скачивает закреплённую сборку libmpv из [shinchiro/mpv-winbuild-cmake](https://github.com/shinchiro/mpv-winbuild-cmake) и автономный `7zr.exe` из 7-Zip для её распаковки, сверяет оба файла с их SHA-256 и помещает в папку `vendor` (в репозиторий она не входит); `build.rs` копирует DLL рядом с исполняемым файлом. Исполняемый файл статически связан со средой выполнения C (`.cargo/config.toml`) и загружает libmpv во время работы, поэтому кроме Windows ему нужна только `libmpv-2.dll`.

## Установщик и выпуск

Сценарий выпуска собирает исполняемый файл, установщик и портативный архив. Для него нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```
python tools/make_release.py              # libmpv, тесты, сборка, установщик, архив
python tools/make_release.py --no-tests   # то же без cargo test
python tools/make_release.py --install    # затем тихая установка поверх установленной копии
```

Сценарий записывает файлы в папку `dist` и берёт версию из `Cargo.toml`. Сценарий установщика — `tools/setup.iss`; значок установщика записывает команда `metalmpv.exe --export-icon <файл.ico>`.

Выпуски на GitHub собирает workflow **Release** (`.github/workflows/release.yml`). Между выпусками версия в `Cargo.toml` содержит `-dev`. Для выпуска суффикс убирается (после `python tools/notices.py`, если изменился `Cargo.lock`: актуальность уведомлений проверяет тест), изменение фиксируется коммитом `Version X.Y.Z`, а отправка соответствующего тега публикует выпуск с установщиком и портативным архивом; затем версия становится следующей с `-dev`:

```
git tag v0.1.0
git push origin v0.1.0
```

Workflow останавливается, если тег не совпадает с версией в `Cargo.toml` или версия ещё содержит суффикс вроде `-dev`. Ручной запуск (Actions → Release → Run workflow) собирает файлы и прикрепляет их к запуску, не создавая выпуска.
