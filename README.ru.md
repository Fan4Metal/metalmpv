<p align="center"><a href="README.md">English</a> | <b>Русский</b></p>

MetalMPV — видеоплеер для Windows с классической компоновкой: изображение занимает всё окно, под ним полоса перемотки и кнопки с «Воспроизвести» посередине, справа открывается список воспроизведения. Воспроизведением занимается [libmpv](https://mpv.io) — библиотека плеера mpv, поэтому воспроизводятся практически все форматы видео и звука, с аппаратным декодированием там, где его поддерживает видеокарта. Программа рассчитана на быстрое открытие файлов и мгновенную перемотку по ключевым кадрам.

![MetalMPV воспроизводит видео, под изображением панель управления](images/screenshot.png)

*Снимок окна версии 0.1.0.*

## Возможности

- **Быстрый запуск**: движок воспроизведения запускается, пока создаётся окно; при повторном запуске первый кадр файла 1080p появляется примерно через 0,4 с после старта программы.
- **Мгновенная перемотка по ключевым кадрам** клавишами-стрелками, точная перемотка и покадровый переход другими клавишами (см. [Горячие клавиши](#горячие-клавиши)); каждая перемотка отображается на экране.
- **Все распространённые форматы**: MP4, MKV, AVI, MOV, WebM, TS, WMV и другие, включая звуковые файлы; субтитры рядом с видео подключаются автоматически.
- **Звуковые дорожки и субтитры** в одном окне у регулятора громкости (`T`), оба списка рядом; субтитры из отдельного файла — через **Загрузить из файла…** или перетаскиванием файла на воспроизводимое видео (см. [Звук и субтитры](#звук-и-субтитры)).
- **Сведения о файле** (`I`): обложка, теги, размер, контейнер и характеристики каждой дорожки в окне, которое остаётся поверх плеера во время воспроизведения; обложка звукового файла занимает место изображения (см. [Сведения о файле](#сведения-о-файле)).
- **Окно под изображение**: 50 %, 100 %, 150 % или 200 % размера видео, наибольшее окно без чёрных полос, окно по размеру изображения или полный экран без чёрных полос (`1`–`6`, `Ё`).
- **Главы**: метки на полосе перемотки, которые можно отключить, и список под плейлистом для перехода к главе (см. [Главы](#главы)).
- **Аппаратное декодирование** (NVDEC, D3D11VA и другие, выбор за libmpv), которое можно отключить в настройках.
- **Настройки звука**: устройство вывода, каналы (автоматически или раскладка, выбранная вручную), усиление громкости до 200 %, нормализация, выравнивающая громкость, и передача звука Dolby и DTS на ресивер без декодирования; звук можно сдвинуть относительно изображения клавишами `Ctrl+=` и `Ctrl+-`.
- **Панель видео, звука и субтитров** (`U`): яркость, контраст, насыщенность, оттенок и гамма, резкость, шумоподавление и сглаживание полос градиента, принудительные пропорции, поворот и отражение, сохранение кадра, десятиполосный эквалайзер с предустановками и вид субтитров: шрифт, размер, цвета, обводка и высота (см. [Панель видео, звука и субтитров](#панель-видео-звука-и-субтитров)).
- **Продолжение просмотра**: фильм при повторном открытии воспроизводится с того места, где был остановлен (см. [Настройки](#настройки)).
- **Плейлист**: файлы, открытые вместе, перетащенные в окно или добавленные кнопкой **+** плейлиста; по желанию — остальные медиафайлы папки открытого файла.
- **Одно окно**: файл, открытый из Проводника при запущенном плеере, воспроизводится в уже открытом окне.
- **Типы файлов**: плеер можно зарегистрировать в Windows для его видео- и аудиоформатов, у каждого из которых свой значок, и выбрать проигрывателем по умолчанию (см. [Типы файлов](#типы-файлов)).
- **Интерфейс на русском или английском**: язык следует языку Windows и меняется в настройках (`F5`).
- **Портативность**: [портативный архив](#установка) хранит настройки рядом с программой.
- **Конфиденциальность**: обращений к сети нет, кроме необязательной проверки обновлений (см. [Проверка обновлений и конфиденциальность](#проверка-обновлений-и-конфиденциальность)).

## Установка

Установщик и портативный архив находятся на странице [Releases](https://github.com/Fan4Metal/metalmpv/releases).

Установщику `MetalMPV_<версия>_Setup.exe` не нужны права администратора: программа устанавливается в `%LOCALAPPDATA%\Programs\MetalMPV`. Установленная программа хранит настройки в `%APPDATA%\MetalMPV`. Задача установщика **Типы файлов**, включённая по умолчанию, регистрирует плеер для его форматов (см. [Типы файлов](#типы-файлов)); на последней странице установщик предлагает открыть параметры Windows, чтобы выбрать плеер проигрывателем по умолчанию. При удалении программы регистрация удаляется; настройки в `%APPDATA%\MetalMPV` (вместе с запомненными позициями и логотипами каналов) сохраняются.

Портативный архив `MetalMPV_<версия>_portable.zip` содержит программу в папке `MetalMPV` и работает без установки. В нём также лежит пустой файл `metalmpv.ron`. Пока этот файл находится рядом с `metalmpv.exe` и папка доступна для записи, настройки хранятся в нём, поэтому программу можно переносить на съёмном носителе. Без этого файла настройки хранятся в `%APPDATA%\MetalMPV`, как у установленной программы. Окно «О программе» показывает, где хранятся настройки.

В обоих вариантах есть `libmpv-2.dll` (около 115 МБ в распакованном виде) — движок воспроизведения; файл должен лежать рядом с `metalmpv.exe`.

Исполняемые файлы не подписаны, поэтому Windows SmartScreen при первом запуске может предупредить о неизвестном издателе.

## Использование

Файл открывается кнопкой **Открыть файл** (значок извлечения, `Ctrl+O`), перетаскиванием в окно, из Проводника (**Открыть с помощью**) или из командной строки: `metalmpv.exe файл.mkv [другие файлы]`. Несколько файлов образуют плейлист; по окончании файла начинается следующий. Плейлист M3U или M3U8, открытый, перетащенный или переданный в командной строке, заменяется своими записями (относительные пути отсчитываются от папки плейлиста); так же, как только mpv его прочитает, заменяется плейлист по адресу (`http://…/list.m3u`) и плейлист, указанный внутри другого. Строки `#EXTINF` списка IPTV задают названия записей: плейлист, заголовок окна и сохранённые кадры показывают название канала вместо имени файла потока, подсказка записи — её группу, а рядом с названием показывается логотип канала (`tvg-logo`; см. **Логотипы каналов** в настройках); **Сохранить плейлист** записывает названия, логотипы и группы обратно. `Ctrl+U` или пункт **Открыть адрес…** контекстного меню воспроизводит прямую ссылку на видео или поток (http, https, rtsp, rtmp, udp и другие; адрес в командной строке тоже принимается); страницы YouTube и других сайтов не поддерживаются, поскольку плеер не использует yt-dlp. Пока ничего не воспроизводится, стартовый экран показывает под заголовком НЕДАВНИЕ, по центру под подсказкой, последние воспроизведённые файлы (до восьми, сколько позволяет высота окна); щелчок воспроизводит файл, а **Очистить список** очищает список, как и **Забыть всё** в разделе «Продолжение просмотра» настроек. При выключенной настройке **Запоминать недавние файлы** файлы не запоминаются. Кнопка программы на панели задач показывает позицию как индикатор выполнения (жёлтый на паузе), а под её миниатюрой есть кнопки **Предыдущий файл**, **Воспроизвести**/**Пауза** и **Следующий файл**. Пока воспроизводится видео, экран не гаснет и компьютер не засыпает; пока звучит только звук, компьютер не засыпает, а на паузе и после окончания воспроизведения снова действуют настройки электропитания Windows.

У окна собственная строка заголовка: окно перемещается перетаскиванием заголовка, изображения или свободного места панели управления, меняет размер за края и разворачивается двойным щелчком по заголовку. Двойной щелчок по изображению или `Enter` включает полноэкранный режим, в котором остаётся только изображение; панель управления внизу и название файла вверху появляются поверх него независимо друг от друга, каждая — пока указатель находится у её края, а сам указатель скрывается через полсекунды покоя вдали от них. Полосу с названием можно отключить, а прозрачность обеих панелей задаётся в настройках.

`1`, `2`, `3` и `4` подгоняют окно так, чтобы изображение показывалось в 50 %, 100 %, 150 % или 200 % размера видео (при 100 % пиксель видео приходится на пиксель экрана), `5` делает окно наибольшим из помещающихся на экране, в пропорциях изображения, так что чёрных полос нет, а `Ё` (`` ` `` в английской раскладке) подгоняет окно под показанное изображение, убирая чёрные полосы. Развёрнутое окно сначала восстанавливается, полноэкранный режим выключается; окно, которое не поместилось бы на экране, уменьшается с сохранением пропорций изображения и по возможности сохраняет своё положение по центру. `6` включает полноэкранный режим, в котором изображение увеличено до заполнения экрана с обрезкой краёв, так что чёрных полос нет; повторное нажатие `6` снова показывает изображение целиком, с чёрными полосами, не выходя из полноэкранного режима; выход из полноэкранного режима тоже возвращает изображение целиком. Те же команды собраны в подменю **Масштаб** контекстного меню изображения. `7` (или пункт **Только видео** контекстного меню) скрывает строку заголовка, панель управления и список воспроизведения, оставляя только изображение: окно уменьшается на занятое ими место, так что изображение остаётся на прежнем месте и того же размера; окно по-прежнему перемещается перетаскиванием изображения и меняет размер за края. Повторное `7`, `Esc` или пункт **Вернуть интерфейс** в начале контекстного меню возвращает их.

На панели управления расположены полоса перемотки (щелчок или перетаскивание переводит воспроизведение в эту точку, время под указателем показывается в подсказке), время (щелчок по нему переключает текущую позицию с длительностью, только текущую позицию и оставшееся время; выбор сохраняется), кнопки **Открыть файл**, **Стоп**, **Предыдущий файл**, **Воспроизвести/Пауза**, **Следующий файл**, **Настройки** и **Список воспроизведения**, громкость и кнопка полноэкранного режима. Щелчок правой кнопкой по изображению открывает меню с теми же командами.

Плейлист (`L`) показывает файлы и выделяет текущий; двойной щелчок воспроизводит файл. Кнопки-значки над плейлистом добавляют файлы (**+**), убирают выбранный (**−**, `Delete`), упорядочивают плейлист по имени, числа — по значению (полоски со стрелкой), очищают его (корзина), сохраняют в плейлист M3U8 (стрелка в лоток), а после черты перемешивают (скрещённые стрелки; текущий файл продолжает играть); их названия видны в подсказках. Кнопка с петлёй рядом с ней, `R` или подменю **Повтор** контекстного меню переключает режим повтора, который запоминается: выключен, файл (воспроизводится снова без паузы) или плейлист (после последнего файла — первый; **Следующий** и **Предыдущий** ходят по кругу).

Кнопка в правом конце ряда кнопок плейлиста (окно со стрелкой) или пункт **Плейлист в отдельном окне** контекстного меню изображения переносит плейлист в отдельное окно и обратно. Это окно, как и окно плеера, без рамки Windows: у него своя строка заголовка (за неё окно перетаскивается, справа — кнопка закрытия), а размер меняется за края; у него нет кнопки на панели задач, оно находится поверх плеера и сворачивается вместе с ним; в первый раз оно встаёт у правого края плеера во всю его высоту. Поднесённое к краю плеера, окно притягивается к нему и выравнивается по верху, низу или боковому краю плеера, как в GOM Player; прилипнув к краю, оно перемещается вместе с плеером и следует за изменением его размера (кроме развёрнутого и полноэкранного режимов). В полноэкранном режиме окно скрыто, если оно закрывало бы экран плеера. Клавиши плеера в нём работают, кроме `Esc`, которая закрывает это окно. Положение и размер окна запоминаются.

### Панель видео, звука и субтитров

`U` (также `F7`, как в GOM Player), кнопка с ползунками слева от кнопки дорожек на панели управления или пункт **Видео, звук и субтитры…** контекстного меню изображения открывает панель в правом верхнем углу плеера (левее окна сведений, если оно тоже открыто; см. **Закрепить панели** в настройках) с вкладками **Видео**, **Звук** и **Субтитры**; воспроизведение и клавиши при этом продолжают работать, а `U`, `F7` или `Esc` закрывает её. На вкладке «Видео» ползунки задают яркость, контраст, насыщенность, оттенок и гамму от −100 до 100, а также резкость (адаптивная резкость AMD, CAS); двойной щелчок по ползунку или круговая стрелка рядом с ним возвращает исходное значение. Шумоподавление сглаживает зерно и шум сжатия, сглаживание полос градиента убирает ступеньки на небе и в тёмных сценах. Пропорции берутся из файла или задаются принудительно: 4:3, 16:9, 16:10, 1.85:1, 2.35:1 или 2.39:1 (также в подменю **Пропорции** контекстного меню изображения). Кнопки поворачивают изображение влево или вправо на 90°, переворачивают его вертикально или отражают зеркально. Резкость, шумоподавление и отражения — фильтры FFmpeg, их выполняет процессор (пока включён любой из них, при аппаратном декодировании каждый кадр копируется для них обратно в память); цвет, поворот и сглаживание полос выполняет видеокарта. Настройки действуют для всех файлов до закрытия программы; **Сбросить всё** возвращает исходные значения.

**Сохранить кадр** (`Ctrl+E`, также в контекстном меню) сохраняет кадр на экране в том виде, в каком он декодирован, без субтитров, в формате PNG с названием файла и позицией в папку «Изображения\MetalMPV»; **Открыть папку** открывает эту папку.

Вкладка «Звук» (также пункт **Эквалайзер…** контекстного меню) содержит десятиполосный эквалайзер от 31 Гц до 16 кГц, ±12 дБ на полосу (двойной щелчок или круговая стрелка под полосой возвращает 0), с предустановками «Ровно», «Рок», «Поп», «Джаз», «Классика», «Басы», «Голос» и «Высокие», а также нормализацию — ту же, что в настройках. Эквалайзер запоминается между запусками; ни он, ни нормализация не действуют на звук, передаваемый на ресивер без декодирования.

Вкладка «Субтитры» начинается с заготовок: обычные, жёлтые, жирные с толстой обводкой, мягкие с тенью, кремовые и на тёмной подложке; каждая задаёт цвета, обводку, тень, жирность и подложку, а шрифт, размер и высоту оставляет как есть (после изменения любого из этих параметров в списке значится «Свой»). Ниже вкладка задаёт шрифт и размер (те же, что в настройках), жирное начертание, цвет букв и обводки, толщину обводки, тень, тёмную полупрозрачную подложку под каждой строкой вместо обводки (цвета обводки; толщина становится её полями) и высоту субтитров на изображении; круговая стрелка рядом с каждым параметром возвращает его исходное значение, а **Сбросить всё** — все сразу. Размер и высота действуют на все субтитры, шрифт и цвета — на текстовые (SRT и подобные): у субтитров ASS свои стили. Вид субтитров запоминается между запусками.

### Главы

Если в файле есть главы, полоса перемотки разделена разрывами в начале каждой из них, а подсказка над полосой называет главу под указателем. Метки отключаются и включаются в подменю **Главы** контекстного меню изображения или в настройках (**Воспроизведение**). Под плейлистом раздел **Главы** перечисляет их с временем начала и выделяет текущую; щелчок переходит к главе, щелчок по заголовку сворачивает раздел. Тот же список есть в подменю **Главы**. Переход отображается на экране с номером и названием главы.

### Переход ко времени

`Ctrl+G` или пункт **Перейти ко времени…** контекстного меню изображения открывает окно, в поле которого стоит текущая позиция, выделенная так, что введённое время её заменяет. Поле принимает `1:23:45`, `83:20`, число секунд (`5000`), дробную часть после точки или запятой (`1:23,5`), долю файла (`50%`) или сдвиг от текущей позиции (`+30`, `-1:00`, `+10%`); под полем окно показывает время, которое получается, и его долю в файле, либо сообщает, что текст не является временем в этом файле. `Enter` или **Перейти** переходит туда с точностью до кадра; время после конца файла ведёт к концу.

### Повтор A-B

`[` (`Х` в русской раскладке) отмечает начало отрезка в текущей позиции, а `]` (`Ъ`) — его конец; после этого воспроизведение каждый раз по достижении конца возвращается к началу, пока `\` не выключит повтор. Конец, отмеченный без начала, повторяет отрезок от начала файла, а конец раньше начала меняет точки местами. Точки показываются жёлтыми рисками на полосе перемотки, отрезок между ними подсвечивается, экранное сообщение называет их с точностью до десятой доли секунды, а подменю **Повтор A-B** контекстного меню изображения делает то же самое. Точки относятся к файлу: другой файл начинается без них.

### Звук и субтитры

Кнопка с облачком речи слева от громкости (`T`) открывает окно, в котором рядом показаны звуковые дорожки и субтитры файла. У каждой дорожки первым указан язык, за ним через тире название дорожки («Русский — Superbit»); под ними плашки показывают формат, число каналов и пометки «внешние», «принудительные», «по умолчанию». Длинный список прокручивается. Выбор применяется сразу, а окно остаётся открытым, поэтому звук и субтитры можно сменить за один раз; щелчок вне окна или `Esc` закрывает его. **Загрузить из файла…** под субтитрами подключает субтитры из отдельного файла (SRT, ASS, SSA, VobSub, PGS, WebVTT); так же подключается файл субтитров, перетащенный на воспроизводимое видео. Субтитры с тем же именем, что у видео, рядом с ним подключаются сами. Те же списки есть в контекстном меню изображения, а каждая смена отображается на экране.

### Сведения о файле

Клавиша `I`, кнопка **i** в строке заголовка или пункт **Сведения о файле** контекстного меню изображения открывает окно поверх плеера; пока оно открыто, воспроизведение продолжается и клавиши работают, а `I` или `Esc` закрывает его. Вверху показаны обложка, название, исполнитель и альбом; щелчок по обложке показывает её в размере, который позволяет окно. Под ними в рядах чипов — главное, чтобы не нужно было прокручивать: файл (формат, размер, длительность, общий битрейт), изображение (кодек, размер кадра, частота кадров, разрядность, HDR, битрейт) и звук — по чипу на каждую звуковую дорожку (кодек, каналы, язык), играющая обведена; щелчок по чипу звуковой дорожки включает её, а если дорожек больше четырёх, остальные свёрнуты в один чип, который перечисляет их в подсказке. Чип субтитров называет их язык и число. Подсказка каждого чипа говорит больше: название контейнера, полное имя кодека и профиль, название и характеристики дорожки. Канал списка IPTV показывается с названием и группой из списка, а вместо обложки — его логотип, когда он загружен. Ниже приведены сведения о файле (имя, папка, размер, контейнер, длительность, общий битрейт, число глав; щелчок по папке показывает файл в Проводнике), его теги (распространённые — первыми и с названиями на языке интерфейса, остальные — так, как они названы в файле) и дорожки, у каждой из которых в одной строке указаны формат, размер кадра, частота кадров, разрядность, HDR, число каналов, частота дискретизации и битрейт. Щелчок по дорожке раскрывает подробности: профиль кодека, соотношение сторон, раскладку каналов, примерный размер потока, признаки и теги дорожки, а для показываемого видео также цветовую субдискретизацию, развёртку, диапазон цветов, основные цвета, передаточную функцию и матрицу, уровни яркости HDR и способ декодирования (аппаратный или программный). Под шапкой расположены две кнопки-значка, названия которых видны в подсказках: **Копировать всё** (два листа) помещает все сведения в буфер обмена текстом и на мгновение показывает галочку, а **Сохранить обложку…** (стрелка в лоток) сохраняет изображение в том виде, в каком оно хранится. Окно находится у правого верхнего угла плеера, в том числе после изменения размера окна плеера; если в настройках выключено **Закрепить панели**, окно перетаскивается за заголовок и остаётся там, где его оставили. Его нижний край можно перетащить, чтобы сделать окно выше или ниже.

Обложка берётся из тегов файла (MP3, FLAC, OGG, Opus, M4A, MP4, WAV, APE и другие) или из его вложений (MKV, MKA, WebM); для звукового файла без обложки используется изображение с именем `cover`, `folder` или `front` рядом с ним. Пока воспроизводится звуковой файл, его обложка занимает место изображения, а под ней указаны название, исполнитель и альбом.

### Типы файлов

Страница **Типы файлов** в настройках (`F5`) показывает, зарегистрирован ли плеер, строки действий с кнопками справа — **Зарегистрировать** (после регистрации — **Обновить**), **Выбрать…** для программы по умолчанию и **Удалить** для удаления регистрации, а также форматы, которые регистрирует плеер, с их расширениями и отметкой, открывает ли плеер каждый из них по умолчанию. Установщик тоже регистрирует форматы.

![Значки зарегистрированных типов файлов](images/file_types.png)

Регистрация выполняется для текущего пользователя и не требует прав администратора. Каждый формат получает собственный тип со значком (цвета — как у GOM Player: свой оттенок для каждого семейства форматов, на видео — знак воспроизведения, на звуке — нота, на плейлистах — список) и названием в столбце «Тип» Проводника; плеер появляется в пункте **Открыть с помощью** для этих файлов и в разделе **Параметры → Приложения → Приложения по умолчанию**. Программу по умолчанию Windows разрешает выбирать только пользователю: **Выбрать…** открывает этот раздел параметров, а Windows сама предлагает плеер при следующем открытии такого файла. Формат, который ещё не открывает ни одна программа, сразу получает плеер программой по умолчанию. **Удалить** удаляет всё, что записала регистрация; выбор другой программы остаётся прежним.

Регистрируемые форматы: видео MP4 (`.mp4`, `.m4v`), MKV, WebM, AVI (`.avi`, `.divx`), MOV (`.mov`, `.qt`), WMV (`.wmv`, `.asf`), FLV (`.flv`, `.f4v`), MPEG (`.mpg`, `.mpeg`, `.m2v`, `.vob`), TS (`.ts`, `.m2ts`, `.mts`), 3GP (`.3gp`, `.3g2`), OGV и RM (`.rm`, `.rmvb`); звук MP3, FLAC, AAC (`.m4a`, `.aac`), Ogg (`.ogg`, `.oga`), Opus, WAV, WMA, APE, WavPack (`.wv`), MKA, AC3 и DTS; плейлисты M3U (`.m3u`, `.m3u8`).

То же самое выполняется из командной строки: `metalmpv.exe --register` и `metalmpv.exe --unregister`.

Кнопка **Сбросить** под списком возвращает параметрам окна и эквалайзеру значения по умолчанию; запомненные позиции, недавние файлы, режим повтора и положение плейлиста сохраняются.

## Горячие клавиши

Ниже приведены клавиши по умолчанию. В настройках категория **Горячие клавиши** перечисляет действия по группам, каждое со своими клавишами: щелчок по клавише ждёт нажатия сочетания (или кнопки мыши «назад» либо «вперёд», при желании с `Ctrl`, `Alt` или `Shift`), которое займёт её место, **+** добавляет ещё одно, крестик удаляет клавишу, а `Esc` отменяет выбор. Сочетание, принадлежавшее другому действию, переходит от него, о чём сообщается на странице. Нескольким действиям без клавиши по умолчанию её можно назначить: «Стоп», «Загрузить субтитры из файла», «Повтор A-B: начало, конец, выключить» (одна клавиша для всех трёх по очереди), «Эквалайзер», «Плейлист в отдельном окне / в окне плеера», «Свернуть окно» и «Развернуть / восстановить окно». **Сбросить клавиши** возвращает все клавиши по умолчанию. Меню и подсказки показывают клавиши в том виде, в каком они назначены. Колесо мыши, двойной и средний щелчки и медиаклавиши остаются такими, как описано; `Ctrl+V` выбрать нельзя.

| Клавиша | Действие |
|---|---|
| `Пробел` | Воспроизведение / пауза |
| `←` / `→`, кнопки мыши «назад» / «вперёд» | Назад / вперёд на короткий шаг (10 с) по ключевым кадрам; кнопки мыши с `Ctrl` или `Shift` — как стрелки |
| `Ctrl+←` / `Ctrl+→` | Назад / вперёд на длинный шаг (60 с) по ключевым кадрам |
| `Shift+←` / `Shift+→` | Назад / вперёд на 1 с точно до кадра |
| `,` / `.` (или `D` / `F`) | Предыдущий / следующий кадр |
| `Home` / `End` | Начало / конец файла |
| `↑` / `↓`, колесо мыши | Громкость выше / ниже |
| `M` | Без звука |
| `T` | Окно звука и субтитров |
| `I` | Окно сведений о файле |
| `U`, `F7` | Панель видео, звука и субтитров |
| `Ctrl+E` | Сохранить кадр в «Изображения\MetalMPV» |
| `O` | Показывает на экране текущую позицию, длительность и текущую главу |
| `Ctrl+G` | Перейти ко времени: окно для времени в файле |

## Проверка обновлений и конфиденциальность

Проверка обновлений необязательна и по умолчанию выключена. При включённом параметре **Проверять при запуске** на странице «Обновления» в настройках программа не чаще раза в сутки запрашивает у GitHub Releases API (`api.github.com`) последний выпуск; кнопка **Проверить сейчас** на той же странице выполняет запрос немедленно. Запрос не содержит ничего, кроме версии программы в заголовке `User-Agent`, и ничего не скачивается и не устанавливается: если есть более новый выпуск, в строке заголовка появляется кнопка с его версией, открывающая страницу выпуска в браузере. В остальном программа обращается к сети только ради открытого: адрес или плейлист с адресами воспроизводится с их сервера, а при включённых **Логотипах каналов** логотипы, указанные списком IPTV, загружаются с их сайтов (только по HTTPS и никогда из локальной сети; см. настройки). Потоки списка IPTV идут от тех, кто держит его серверы; они видят адрес компьютера и то, что на нём смотрят. `youtube-dl`/yt-dlp не используется.

## Сборка

Требования: Windows 10 или новее, стабильный Rust (цель MSVC, редакция 2024), Visual Studio 2022 Build Tools с компонентом C++ и Python 3. Для `build.py` — [uv](https://docs.astral.sh/uv/).

```
uv run build.py          # target\release\metalmpv.exe и рядом libmpv-2.dll
cargo test
```

`build.py` закрывает `metalmpv.exe`, запущенный из папки `target` проекта (он заблокировал бы файл), при отсутствии загружает libmpv (`tools/get_libmpv.py`) и запускает `cargo build --release`. `tools/get_libmpv.py` скачивает закреплённую сборку libmpv из [shinchiro/mpv-winbuild-cmake](https://github.com/shinchiro/mpv-winbuild-cmake) и автономный `7zr.exe` из 7-Zip для её распаковки, сверяет оба файла с их SHA-256 и помещает в папку `vendor` (в репозиторий она не входит); `build.rs` копирует DLL рядом с исполняемым файлом. Исполняемый файл статически связан со средой выполнения C (`.cargo/config.toml`) и загружает libmpv во время работы, поэтому кроме Windows ему нужна только `libmpv-2.dll`.

## Установщик и выпуск

Сценарий выпуска собирает исполняемый файл, установщик и портативный архив. Для него нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```
python tools/make_release.py              # libmpv, тесты, сборка, установщик, архив
python tools/make_release.py --no-tests   # то же без cargo test
python tools/make_release.py --install    # затем тихая установка поверх установленной копии
```

Сценарий записывает файлы в папку `dist` и берёт версию из `Cargo.toml`. Сценарий установщика — `tools/setup.iss`; значок установщика записывает команда `metalmpv.exe --export-icon <файл.ico>`.

Выпуски на GitHub собирает workflow **Release** (`.github/workflows/release.yml`). Между выпусками версия в `Cargo.toml` содержит `-dev`. Для выпуска суффикс убирается (после `python tools/notices.py`, если изменился `Cargo.lock`: актуальность уведомлений проверяет тест), изменение фиксируется коммитом `Version X.Y.Z`, а отправка соответствующего тега публикует выпуск с установщиком и портативным архивом; затем версия становится следующей с `-dev`:

```
git tag v0.1.0
git push origin v0.1.0
```

Workflow останавливается, если тег не совпадает с версией в `Cargo.toml` или версия ещё содержит суффикс вроде `-dev`. Ручной запуск (Actions → Release → Run workflow) собирает файлы и прикрепляет их к запуску, не создавая выпуска.
