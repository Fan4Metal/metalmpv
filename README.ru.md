<p align="center"><a href="README.md">English</a> | <b>Русский</b></p>

MetalMPV — видеоплеер для Windows с классической компоновкой: изображение занимает всё окно, под ним полоса перемотки и кнопки с «Воспроизвести» посередине, справа открывается список воспроизведения. Воспроизведением занимается [libmpv](https://mpv.io) — библиотека плеера mpv, поэтому воспроизводятся практически все форматы видео и звука, с аппаратным декодированием там, где его поддерживает видеокарта. Программа рассчитана на быстрое открытие файлов и мгновенную перемотку по ключевым кадрам.

![MetalMPV воспроизводит видео, под изображением панель управления](images/screenshot.png)

*Снимок окна версии 0.1.0.*

## Возможности

- **Быстрый запуск**: движок воспроизведения запускается, пока создаётся окно; при повторном запуске первый кадр файла 1080p появляется примерно через 0,4 с после старта программы.
- **Мгновенная перемотка по ключевым кадрам** клавишами-стрелками, точная перемотка и покадровый переход другими клавишами (см. [Горячие клавиши](#горячие-клавиши)); каждая перемотка отображается на экране.
- **Все распространённые форматы**: MP4, MKV, AVI, MOV, WebM, TS, WMV и другие, включая звуковые файлы; субтитры рядом с видео подключаются автоматически.
- **Звуковые дорожки и субтитры** в одном окне у регулятора громкости (`T`), оба списка рядом; субтитры из отдельного файла — через **Загрузить из файла…** или перетаскиванием файла на воспроизводимое видео (см. [Звук и субтитры](#звук-и-субтитры)).
- **Сведения о файле** (`I`): обложка, теги, размер, контейнер и характеристики каждой дорожки в окне, которое остаётся поверх плеера во время воспроизведения; обложка звукового файла занимает место изображения (см. [Сведения о файле](#сведения-о-файле)).
- **Окно под изображение**: 50 %, 100 %, 150 % или 200 % размера видео, наибольшее окно без чёрных полос, окно по размеру изображения или полный экран без чёрных полос (`1`–`6`, `Ё`).
- **Главы**: метки на полосе перемотки, которые можно отключить, и список под списком воспроизведения для перехода к главе (см. [Главы](#главы)).
- **Аппаратное декодирование** (NVDEC, D3D11VA и другие, выбор за libmpv), которое можно отключить в настройках.
- **Настройки звука**: устройство вывода, каналы (автоматически или раскладка, выбранная вручную), усиление громкости до 200 %, нормализация, выравнивающая громкость, и передача звука Dolby и DTS на ресивер без декодирования; звук можно сдвинуть относительно изображения клавишами `Ctrl+=` и `Ctrl+-`.
- **Панель видео** (`F7`): яркость, контраст, насыщенность, оттенок и гамма, резкость, шумоподавление и сглаживание полос градиента, принудительные пропорции, поворот и отражение, сохранение кадра (см. [Панель видео](#панель-видео)).
- **Продолжение просмотра**: фильм при повторном открытии воспроизводится с того места, где был остановлен (см. [Настройки](#настройки)).
- **Список воспроизведения**: файлы, открытые вместе, перетащенные в окно или добавленные кнопкой **+** списка воспроизведения; по желанию — остальные медиафайлы папки открытого файла.
- **Одно окно**: файл, открытый из Проводника при запущенном плеере, воспроизводится в уже открытом окне.
- **Типы файлов**: плеер можно зарегистрировать в Windows для его видео- и аудиоформатов, у каждого из которых свой значок, и выбрать проигрывателем по умолчанию (см. [Типы файлов](#типы-файлов)).
- **Интерфейс на русском или английском**: язык следует языку Windows и меняется в настройках (`F5`).
- **Портативность**: [портативный архив](#установка) хранит настройки рядом с программой.
- **Конфиденциальность**: обращений к сети нет, кроме необязательной проверки обновлений (см. [Проверка обновлений и конфиденциальность](#проверка-обновлений-и-конфиденциальность)).

## Установка

Установщик и портативный архив находятся на странице [Releases](https://github.com/Fan4Metal/metalmpv/releases).

Установщику `MetalMPV_<версия>_Setup.exe` не нужны права администратора: программа устанавливается в `%LOCALAPPDATA%\Programs\MetalMPV`. Установленная программа хранит настройки в `%APPDATA%\MetalMPV`. Задача установщика **Типы файлов**, включённая по умолчанию, регистрирует плеер для его форматов (см. [Типы файлов](#типы-файлов)); на последней странице установщик предлагает открыть параметры Windows, чтобы выбрать плеер проигрывателем по умолчанию. При удалении программы регистрация удаляется.

Портативный архив `MetalMPV_<версия>_portable.zip` содержит программу в папке `MetalMPV` и работает без установки. В нём также лежит пустой файл `metalmpv.ron`. Пока этот файл находится рядом с `metalmpv.exe` и папка доступна для записи, настройки хранятся в нём, поэтому программу можно переносить на съёмном носителе. Без этого файла настройки хранятся в `%APPDATA%\MetalMPV`, как у установленной программы. Окно «О программе» показывает, где хранятся настройки.

В обоих вариантах есть `libmpv-2.dll` (около 115 МБ в распакованном виде) — движок воспроизведения; файл должен лежать рядом с `metalmpv.exe`.

Исполняемые файлы не подписаны, поэтому Windows SmartScreen при первом запуске может предупредить о неизвестном издателе.

## Использование

Файл открывается кнопкой **Открыть файл** (значок извлечения, `Ctrl+O`), перетаскиванием в окно, из Проводника (**Открыть с помощью**) или из командной строки: `metalmpv.exe файл.mkv [другие файлы]`. Несколько файлов образуют список воспроизведения; по окончании файла начинается следующий.

У окна собственная строка заголовка: окно перемещается перетаскиванием заголовка, изображения или свободного места панели управления, меняет размер за края и разворачивается двойным щелчком по заголовку. Двойной щелчок по изображению или `Enter` включает полноэкранный режим, в котором остаётся только изображение; панель управления внизу и название файла вверху появляются поверх него независимо друг от друга, каждая — пока указатель находится у её края, а сам указатель скрывается через полсекунды покоя вдали от них. Полосу с названием можно отключить, а прозрачность обеих панелей задаётся в настройках.

`1`, `2`, `3` и `4` подгоняют окно так, чтобы изображение показывалось в 50 %, 100 %, 150 % или 200 % размера видео (при 100 % пиксель видео приходится на пиксель экрана), `5` делает окно наибольшим из помещающихся на экране, в пропорциях изображения, так что чёрных полос нет, а `Ё` (`` ` `` в английской раскладке) подгоняет окно под показанное изображение, убирая чёрные полосы. Развёрнутое окно сначала восстанавливается, полноэкранный режим выключается; окно, которое не поместилось бы на экране, уменьшается с сохранением пропорций изображения и по возможности сохраняет своё положение по центру. `6` включает полноэкранный режим, в котором изображение увеличено до заполнения экрана с обрезкой краёв, так что чёрных полос нет; повторное нажатие `6` снова показывает изображение целиком, с чёрными полосами, не выходя из полноэкранного режима; выход из полноэкранного режима тоже возвращает изображение целиком. Те же команды собраны в подменю **Масштаб** контекстного меню изображения.

На панели управления расположены полоса перемотки (щелчок или перетаскивание переводит воспроизведение в эту точку, время под указателем показывается в подсказке), время (щелчок по нему переключает текущую позицию с длительностью, только текущую позицию и оставшееся время; выбор сохраняется), кнопки **Открыть файл**, **Стоп**, **Предыдущий файл**, **Воспроизвести/Пауза**, **Следующий файл**, **Настройки** и **Список воспроизведения**, громкость и кнопка полноэкранного режима. Щелчок правой кнопкой по изображению открывает меню с теми же командами.

Список воспроизведения (`L`) показывает файлы и выделяет текущий; двойной щелчок воспроизводит файл. Кнопки-значки над списком добавляют файлы (**+**), убирают выбранный (**−**, `Delete`), упорядочивают список по имени, числа — по значению (полоски со стрелкой), и очищают его (корзина); их названия видны в подсказках.

### Панель видео

`F7` или пункт **Настройки видео…** контекстного меню изображения открывает панель поверх плеера; воспроизведение и клавиши при этом продолжают работать, а `F7` или `Esc` закрывает её. Ползунки задают яркость, контраст, насыщенность, оттенок и гамму от −100 до 100 (двойной щелчок возвращает 0), а также резкость (адаптивная резкость AMD, CAS). Шумоподавление сглаживает зерно и шум сжатия, сглаживание полос градиента убирает ступеньки на небе и в тёмных сценах. Пропорции берутся из файла или задаются принудительно: 4:3, 16:9, 16:10, 1.85:1, 2.35:1 или 2.39:1 (также в подменю **Пропорции** контекстного меню изображения). Кнопки поворачивают изображение влево или вправо на 90°, переворачивают его вертикально или отражают зеркально. Резкость, шумоподавление и отражения — фильтры FFmpeg, их выполняет процессор (кадр, декодированный видеокартой, для них копируется обратно); цвет, поворот и сглаживание полос выполняет видеокарта. Настройки действуют для всех файлов до закрытия программы; **Сбросить всё** возвращает исходные значения.

**Сохранить кадр** (`Ctrl+E`, также в контекстном меню) сохраняет кадр на экране в том виде, в каком он декодирован, без субтитров, в формате PNG с названием файла и позицией в папку «Изображения\MetalMPV»; **Открыть папку** открывает эту папку.

### Главы

Если в файле есть главы, полоса перемотки разделена разрывами в начале каждой из них, а подсказка над полосой называет главу под указателем. Метки отключаются и включаются в подменю **Главы** контекстного меню изображения или в настройках (**Воспроизведение**). Под списком воспроизведения раздел **Главы** перечисляет их с временем начала и выделяет текущую; щелчок переходит к главе, щелчок по заголовку сворачивает раздел. Тот же список есть в подменю **Главы**. Переход отображается на экране с номером и названием главы.

### Звук и субтитры

Кнопка с облачком речи слева от громкости (`T`) открывает окно, в котором рядом показаны звуковые дорожки и субтитры файла. У каждой дорожки первым указан язык, за ним через тире название дорожки («Русский — Superbit»); под ними плашки показывают формат, число каналов и пометки «внешние», «принудительные», «по умолчанию». Длинный список прокручивается. Выбор применяется сразу, а окно остаётся открытым, поэтому звук и субтитры можно сменить за один раз; щелчок вне окна или `Esc` закрывает его. **Загрузить из файла…** под субтитрами подключает субтитры из отдельного файла (SRT, ASS, SSA, VobSub, PGS, WebVTT); так же подключается файл субтитров, перетащенный на воспроизводимое видео. Субтитры с тем же именем, что у видео, рядом с ним подключаются сами. Те же списки есть в контекстном меню изображения, а каждая смена отображается на экране.

### Сведения о файле

Клавиша `I`, кнопка **i** в строке заголовка или пункт **Сведения о файле** контекстного меню изображения открывает окно поверх плеера; пока оно открыто, воспроизведение продолжается и клавиши работают, а `I` или `Esc` закрывает его. Вверху показаны обложка, название, исполнитель и альбом; щелчок по обложке показывает её в размере, который позволяет окно. Ниже приведены сведения о файле (имя, папка, размер, контейнер, длительность, общий битрейт, число глав; щелчок по папке показывает файл в Проводнике), его теги (распространённые — первыми и с названиями на языке интерфейса, остальные — так, как они названы в файле) и дорожки, у каждой из которых в одной строке указаны формат, размер кадра, частота кадров, разрядность, HDR, число каналов, частота дискретизации и битрейт. Щелчок по дорожке раскрывает подробности: профиль кодека, соотношение сторон, раскладку каналов, примерный размер потока, признаки и теги дорожки, а для показываемого видео также цветовую субдискретизацию, развёртку, диапазон цветов, основные цвета, передаточную функцию и матрицу, уровни яркости HDR и способ декодирования (аппаратный или программный). Под шапкой расположены две кнопки-значка, названия которых видны в подсказках: **Копировать всё** (два листа) помещает все сведения в буфер обмена текстом и на мгновение показывает галочку, а **Сохранить обложку…** (стрелка в лоток) сохраняет изображение в том виде, в каком оно хранится. Окно находится у правого верхнего угла плеера, в том числе после изменения размера окна плеера; если в настройках выключено **Закрепить окно сведений**, окно перетаскивается за заголовок и остаётся там, где его оставили. Его нижний край можно перетащить, чтобы сделать окно выше или ниже.

Обложка берётся из тегов файла (MP3, FLAC, OGG, Opus, M4A, MP4, WAV, APE и другие) или из его вложений (MKV, MKA, WebM); для звукового файла без обложки используется изображение с именем `cover`, `folder` или `front` рядом с ним. Пока воспроизводится звуковой файл, его обложка занимает место изображения, а под ней указаны название, исполнитель и альбом.

### Типы файлов

Страница **Типы файлов** в настройках (`F5`) показывает, зарегистрирован ли плеер, строки действий с кнопками справа — **Зарегистрировать** (после регистрации — **Обновить**), **Выбрать…** для программы по умолчанию и **Удалить** для удаления регистрации, а также форматы, которые регистрирует плеер, с их расширениями и отметкой, открывает ли плеер каждый из них по умолчанию. Установщик тоже регистрирует форматы.

![Значки зарегистрированных типов файлов](images/file_types.png)

Регистрация выполняется для текущего пользователя и не требует прав администратора. Каждый формат получает собственный тип со значком (цвета — как у GOM Player: свой оттенок для каждого семейства форматов, на видео — знак воспроизведения, на звуке — нота) и названием в столбце «Тип» Проводника; плеер появляется в пункте **Открыть с помощью** для этих файлов и в разделе **Параметры → Приложения → Приложения по умолчанию**. Программу по умолчанию Windows разрешает выбирать только пользователю: **Выбрать…** открывает этот раздел параметров, а Windows сама предлагает плеер при следующем открытии такого файла. Формат, который ещё не открывает ни одна программа, сразу получает плеер программой по умолчанию. **Удалить** удаляет всё, что записала регистрация; выбор другой программы остаётся прежним.

Регистрируемые форматы: видео MP4 (`.mp4`, `.m4v`), MKV, WebM, AVI (`.avi`, `.divx`), MOV (`.mov`, `.qt`), WMV (`.wmv`, `.asf`), FLV (`.flv`, `.f4v`), MPEG (`.mpg`, `.mpeg`, `.m2v`, `.vob`), TS (`.ts`, `.m2ts`, `.mts`), 3GP (`.3gp`, `.3g2`), OGV и RM (`.rm`, `.rmvb`); звук MP3, FLAC, AAC (`.m4a`, `.aac`), Ogg (`.ogg`, `.oga`), Opus, WAV, WMA, APE, WavPack (`.wv`), MKA, AC3 и DTS.

То же самое выполняется из командной строки: `metalmpv.exe --register` и `metalmpv.exe --unregister`.

### Настройки

Окно настроек (`F5` или кнопка с шестерёнкой) содержит слева список категорий, справа — параметры выбранной категории, собранные в группы: в каждой строке указано название параметра, под ним пояснение, справа элемент управления. Кнопка **Сбросить** под списком возвращает всем параметрам значения по умолчанию.

| Категория | Параметр | По умолчанию | Назначение |
|---|---|---|---|
| Общие | Язык | как в Windows | «Системный» следует языку Windows |
| Общие | Закрепить окно сведений | вкл. | Окно сведений о файле стоит в правом верхнем углу плеера; когда выключено, перетаскивается за заголовок |

## Проверка обновлений и конфиденциальность

Проверка обновлений необязательна и по умолчанию выключена. При включённом параметре **Проверять при запуске** на странице «Обновления» в настройках программа не чаще раза в сутки запрашивает у GitHub Releases API (`api.github.com`) последний выпуск; кнопка **Проверить сейчас** на той же странице выполняет запрос немедленно. Запрос не содержит ничего, кроме версии программы в заголовке `User-Agent`, и ничего не скачивается и не устанавливается: если есть более новый выпуск, в строке заголовка появляется кнопка с его версией, открывающая страницу выпуска в браузере. В остальном программа к сети не обращается; сетевые возможности libmpv (потоковое воспроизведение, `youtube-dl`) не используются.

## Сборка

Требования: Windows 10 или новее, стабильный Rust (цель MSVC, редакция 2024), Visual Studio 2022 Build Tools с компонентом C++ и Python 3. Для `build.py` — [uv](https://docs.astral.sh/uv/).

```
uv run build.py          # target\release\metalmpv.exe и рядом libmpv-2.dll
cargo test
```

`build.py` закрывает `metalmpv.exe`, запущенный из папки `target` проекта (он заблокировал бы файл), при отсутствии загружает libmpv (`tools/get_libmpv.py`) и запускает `cargo build --release`. `tools/get_libmpv.py` скачивает закреплённую сборку libmpv из [shinchiro/mpv-winbuild-cmake](https://github.com/shinchiro/mpv-winbuild-cmake) и автономный `7zr.exe` из 7-Zip для её распаковки, сверяет оба файла с их SHA-256 и помещает в папку `vendor` (в репозиторий она не входит); `build.rs` копирует DLL рядом с исполняемым файлом. Исполняемый файл статически связан со средой выполнения C (`.cargo/config.toml`) и загружает libmpv во время работы, поэтому кроме Windows ему нужна только `libmpv-2.dll`.

## Установщик и выпуск

Сценарий выпуска собирает исполняемый файл, установщик и портативный архив. Для него нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```
python tools/make_release.py              # libmpv, тесты, сборка, установщик, архив
python tools/make_release.py --no-tests   # то же без cargo test
python tools/make_release.py --install    # затем тихая установка поверх установленной копии
```

Сценарий записывает файлы в папку `dist` и берёт версию из `Cargo.toml`. Сценарий установщика — `tools/setup.iss`; значок установщика записывает команда `metalmpv.exe --export-icon <файл.ico>`.

Выпуски на GitHub собирает workflow **Release** (`.github/workflows/release.yml`). После обновления версии в `Cargo.toml` и коммита отправка соответствующего тега публикует выпуск с установщиком и портативным архивом:

```
git tag v0.1.0
git push origin v0.1.0
```

Workflow останавливается, если тег не совпадает с версией в `Cargo.toml`. Ручной запуск (Actions → Release → Run workflow) собирает файлы и прикрепляет их к запуску, не создавая выпуска.
